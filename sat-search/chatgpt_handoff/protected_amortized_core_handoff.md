## 1. Strengthen the stopping invariant: uniform derivative contrast

The protected family has two types of queries on its entire data cube F2^D:
- p=1, all selectors s=0: output identically one, independent of x.
- p=1, exactly slot i selected, lambda=e_j: output exactly physical data coordinate x_(i,j).

Thus for every nonzero data direction v, the empty query has derivative identically zero in direction v, and some singleton query has derivative identically one, for ALL basepoints x. This is stronger for the present purpose than the earlier relative degree bound. The proof needs no assumption that the full hard mode is an affine disperser.

Generalize the data parameterization from jointly affine x(u,y) to
    x(u,y)=A u + b(y),
where A is a FIXED injective binary linear map and b may be an arbitrary function of the protected query y. All queries remain available. Keep d data parameter coordinates, h disjoint pairs of signed coordinate literals constrained to have product zero, and effective dimension a=d-h. For every individual data coordinate j there are two allowed data assignments differing only in j (set its paired partner to its blocking phase if necessary), identically for every y. Their physical data difference is the same nonzero column A_j for all y. Therefore:
1. Every data parameter is essential for at least one protected query.
2. An output of the form alpha dot u + beta(y), with FIXED alpha, cannot realize the family unless d=0. On the two selected assignments its derivative would be alpha_j for every query, whereas empty and singleton queries demand different derivatives. This holds even on the paired domain. In particular a=0 iff d=h=0.
3. A query-only output is impossible while any data parameter remains.

The old degree lemma still holds with arbitrary b(y), since each query fiber has the same direction space after choosing one blocking member per pair. We no longer need to stop at a<=2ell: a completely affine output is impossible at ANY positive remaining dimension. This is an abstract contrast condition for a query family, not a claim about every scalar SAT restriction.

## 2. Generalized fair-system representation and query-only freezing

Reuse the earlier fair affine system: a square invertible binary coefficient matrix on its auxiliaries, with each original equation involving at most three variable/literal terms; the right-hand side may now include fixed query-only signals. Parameters are data coordinates and protected query coordinates/functions. For each y, all affine auxiliary values are uniquely defined for EVERY assignment of data parameters, even outside the paired domain. Their data gradients are fixed across y. A separate acyclic B2 circuit reads these signals and earlier binary gates. No affine equation reads a still-active binary gate. Count one unit for each affine equation or active binary gate, denoted s. Stable unit IDs are retained when converting a gate into an equation. Initial affine embedding overhead E<=t/2+P_dictionary-ell-1 as previously, and original circuit B2 gate count B gives s_initial<=B+E (after constant/alias normalization).

A minimal gate has both operands among affine sources. If it is affine (XOR/XNOR, or constant/unary), turn it into a uniquely solvable fresh affine equation of at most three terms or simplify it; this cannot increase s or the number of used unpaired data parameters. The acyclic binary gate count decreases. If a minimal AND-type gate's two affine operands have ZERO gradients on ALL d data coordinates, its output is just some function of y. Freeze it as a new query-only source, without adding any equation or new independent parameter. The physical map still has common A. This is a relaxation of the intermediate representation: the frozen function may be arbitrary and its implementation is NOT asserted to be a single free physical gate. Keep its original gate ID as a charged token F, remove it from s, and never charge that ID again. This is sound for the lower-bound accounting: we are allowing arbitrary query-only sources in the auxiliary representation, the stopping invariant remains valid for them, and the initial counted units partition into active, eliminated, and frozen tokens. No claim of actual physical removal of every gate used to compute a frozen function. We may subsequently simplify affine equations even if their old values helped define an already frozen function; the frozen function is a fixed function of y in the relaxed representation. No circular dependency is introduced by its definition, which is taken at the time of freezing. Because its data gradient was zero, subsequent restrictions on u cannot change its value for a fixed y.

The prior role exchanges remain valid: exchanging an unpaired data parameter with an actual affine operand uses a nonzero data coefficient, changes the data basis by a fixed invertible matrix and updates b(y) by a possibly nonlinear query-only offset. No arbitrary affine operand is manufactured as a free signal. Equations are retained; invertibility and three-term width preserved. Pair constraints use actual signed parameter literals (alternatively reorient the newly promoted parameters by affine constant shifts). Previous pairs and y untouched.

## 3. Pair retirement: a complete rank-zero fallback

Consider a minimal nonlinear gate whose operands have rank ZERO on unpaired data, but at least one has a nonzero coefficient on a paired data parameter u. Retire that pair (u,v): fix v's paired literal to zero and release u from the pair. The original domain is restricted to one branch of the pair; every assignment of surviving coordinates is allowed subject to the other pairs. d decreases by one, h decreases by one, and a=d-h is unchanged. Query freedom and the common injective data direction map are preserved. The surviving u becomes unpaired; it can supply a data pivot in a future move unless the gate already simplifies.

**Reader deletion lemma.** Fixing a parameter to a constant removes at least as many counted units as its distinct direct reader units, including affine equations and binary gates. Binary readers become unary or constant and simplify. An affine equation containing the fixed parameter now has at most two variable terms. It has at least one auxiliary coefficient, since the coefficient matrix on auxiliaries is invertible. Eliminate such an auxiliary by an alias/constant substitution; delete that equation's original ID. Repeat for all originally affected equations. Alias substitution cannot increase equation term count, and ordinary pivot elimination preserves invertibility on the surviving auxiliaries. An affected row cannot become an all-parameter equation in the invertible remaining system; this justifies the next auxiliary elimination. If both gate and equation readers exist, their IDs are distinct. If a gate is removed by earlier propagation, it is already counted once, not counted again. Dead pruning only adds savings. Count actual removed units, not unfolded occurrences.

By Section 1 the fixed pair member v is essential somewhere on the current domain. It must occur in at least one reader unit, unless the entire output is just that parameter (excluded by the affine stopping invariant). Thus retirement removes at least one unit. If a pair member has >=2 direct reader units, fixing it is a potential-neutral retirement or better; if it has >=4, it gives at least two units of surplus. For the rank-zero fallback, choose the branch whose surviving member has nonzero gradient when seeking that particular pivot. The higher-reader branch need not have that property, but even then retirement is legal and makes progress in the total unit/pair count.

For W=s+4h+6I_D, where I_D counts used unpaired data parameters, retirement with J actual removed units has
    Delta a=0, Delta s=-J, Delta h=-1, Delta I_D<=1,
    Delta W<=2-J.
I_D excludes query sources. No unchanged unused unpaired parameter can gain a direct occurrence from constant substitution or alias simplification: the surviving replacement literal was already used in the removed unit. The fixed parameter and released paired parameter are the only data roles changing. The inequality is valid even without asserting that every unpaired parameter has a particular direct reader count.

This resolves rank zero in the WEAKER algorithm, not at the desired guaranteed ten-unit amortized rate: query-only cases use freezing; paired-data cases use retirement, which can have a one-unit potential cost if J=1.

## 4. Complete weaker elimination algorithm

Assume original protected query family satisfies Section 1, full query projection retained. At any positive a, the live binary part cannot be empty by the affine stopping invariant. Prune dead binary gates; take a minimal gate (one exists in a finite DAG). Convert affine gates into equations or simplify. For an AND-type gate, classify its two operand gradients on unpaired data:
- rank two: perform the previous rank-two promotion and pairing move, removing the gate and at least one distinct live successor. a decreases one, s decreases at least two, h increases one. The AND gate cannot itself be the output at this step: after pairing it would become constant while a>=1 still remains (rank two needs at least two independent unpaired coordinates), contradicting Section 1.
- rank one (or rank-two fallback): promote a nonzero-gradient operand and fix its controlling value. a decreases one; remove the gate and at least one distinct successor, except possibly when the gate is the output. If the gate is output, the resulting constant output forces a=0 by Section 1, so there is at most ONE such one-gate terminal move in the entire process.
- rank zero, zero gradient on all data: freeze as query-only. a unchanged; s decreases one and a frozen token is retained. Cannot be the output at positive a.
- rank zero, nonzero paired gradient: retire a pair as above. a unchanged, s decreases at least one.

Every iteration either decreases s (active unit count), or moves one affine binary gate to an equation while preserving s and decreasing the number of active binary gates. This lexicographic potential is nonnegative, so the procedure terminates. At positive a a legal next move always exists, thus it reaches a=0. Pairing is optional (rank-one fixing always available for nonzero unpaired rank). This is a COMPLETE protected elimination procedure in the RELAXED query-source representation, not a full adaptation of the Mishra-Santhanam ten-unit iteration. It uses only selector contrast, not hardness of the incidence subfamily. A one-phase terminal move and signed pair orientations are explicitly allowed. No arbitrary new physical gate or unit is inserted; original affine embedding preprocessing is counted once. If the starting circuit has constants/unary gates, normalization cannot increase its size.

## 5. Exact amortized compensation ledger

Let R count data-fixing moves (including rank-two fallback), P count pairing moves, T count retirements, F count frozen query-only gate tokens. Initially d=D,h=0; finally d=h=0. Thus
    R+P=D, T=P.
Let J_j>=1 be the actual units removed by the j-th retirement. Let X>=0 be actual extra original-unit deletions above the two-unit rank move baseline (one-unit baseline for the possible last output move), plus any standalone normalization/dead-pruning savings. Let L in {0,1} record the terminal one-unit move. Let s_f>=0 be the remaining units at a=0. If every removed/frozen/retained unit is charged once, the actual accounting is
    s_initial = 2D-L + sum_j J_j + F + X + s_f,
and in particular
    B+E >= 2D-1 + sum_j J_j + F + X + s_f
          >= 2D-1 + P + F.
Equivalently, with T=P,
    B+E >= 4D-1 - 2R - sum_j(2-J_j) + F + X + s_f.
This is the exact requested deficit/compensation criterion (with actual initial normalization included consistently). A four-unit retirement gives a two-unit refund against a rank-one deficit; a two-unit retirement is neutral; a one-unit retirement adds one deficit. Extra deletions, frozen tokens and final residual units are also positive reserves. They cannot be claimed twice. The two formulae are algebraically equivalent; the simpler one shows that this is fundamentally original-unit accounting, not a new numerical miracle from the choice of potential.

There is now an unconditional B2 lower bound >=2D-1-E on this affine embedded SAT family, from the complete process. It is NOT a new improvement over existing selector/data-ancestry bounds, or the much stronger verified full physical SAT bound (encoding overhead and basis matter). The refined bound is path/topology-dependent: it holds for any actual elimination sequence of the specified type; no universal lower bound on P or on the surplus is proved. To recover 4D-o(D), one would need R plus uncompensated retirement penalties to be o(D), or enough actual refunds to cover them. The simpler selector-only F(x,s)=AND_i(NOT s_i OR x_i) has 2D-1 binary gates, satisfies uniform derivative contrast, and repeatedly fixing x_i=1 in a conjunction chain removes exactly two units except for the last one. R=D, P=F=0, no compensating surplus. This is a concrete counterexample to any generic theorem asserting that contrast forces later repayment of rank-one deficits. With lambda varying the prior selector-only family still has <=2D+t-1 gates. Neither is a full hard-mode SAT circuit. Thus real progress toward a stronger coefficient must use genuine existential semantics rather than selector contrast alone. Even a 4D slice result would not settle the original full physical size target.

## 6. New hard-core invariant surviving arbitrary affine losses

This complements the completed local algorithm with a semantic reserve from the actual hard mode. Consider ANY common-direction affine fibers x=b(y)+V in the physical payload cube, where dim V=a (b(y) may be arbitrary). In a paired state choose one member of every pair to fix to its blocking phase, identically for every y; the resulting affine fibers have dimension a=d-h. Write them as L x=c(y), with L a full-row-rank r-by-D matrix, r=D-a. A subset of physical groups J is sufficient to absorb the constraints iff the columns L_J in the 3ell|J| coordinates of those groups span F2^r. Choose a column basis and let J be the groups containing those pivot columns. Then |J|<=r (may be much smaller). For every fixed query y and arbitrary assignment of the other groups C, solve the pivot coordinates inside J uniquely after fixing all other coordinates in J arbitrarily. Hence the projection onto all 3ell|C| raw core bits is SURJECTIVE in EVERY query fiber.

Set the three selectors of every group in J to zero. In unit mode their literals use distinct fresh unforced tags. In hard mode p=0 their tags are (i+2) XOR 1, still distinct fresh unforced tags because t=3m is even; every such group's clauses have a satisfying extension independently of ALL their payload values. This follows directly from the existing affine tag formula and guard semantics, not a new encoding. Keep all core selectors, lambda and p free. On each fiber the verdict is exactly the same protected family on C, independent of the eliminated groups' payloads. In particular p=0 and all core selectors one realizes arbitrary H_(|C|,ell) incidence, not merely a constant hard-mode point. Fresh tag names can be renumbered without changing semantics. The physical core coordinates have not moved. Thus
    |C| >= max(0,m-r)
unconstrained clause groups survive, and the exact stronger certificate is m minus the minimum number of column blocks spanning the full constraint row space. This can be checked by Gaussian elimination for a proposed J; the simple coordinate-basis cover is polynomial. Do not claim optimal group cover is efficiently computable.

The group-loss certificate can be updated under nested common-direction affine restrictions: if one additional independent constraint is imposed, the previously absorbing outside group set either spans the enlarged constraint space or can be augmented by ONE more group containing a missing pivot column. Thus at most one group must be deactivated per added affine codimension. A retirement that fixes the branch already chosen in a paired domain need not add a new affine codimension for this semantic reserve; changing branch may change the direction and requires recomputation. The basic theorem is snapshot-based and does not assume a particular branch choice across the entire algorithm.

This is an exact semantic invariant, not a cost-free circuit reduction to ordinary hard-core inputs. To derive a hard-core circuit size bound from the remaining fair system, one must pay for a right inverse mapping free core coordinates to remaining parameters (or prove its cost is already in the unit ledger). Arbitrary dense affine reparameterization is not free. In particular do not add C(H_core) to the above eliminated-unit count without such a cost analysis. Also after r>=m the crude core guarantee can be zero, though actual group cover may remain smaller; this alone cannot force an asymptotically large compensation throughout D=3m ell moves. As a basic hard-mode check, on any surviving core with g>=2 one can pin witness v_0=true using one clause, use all three variable IDs v_0 in each other clause with independent polarity bits, and obtain AND of g-1 ORs of three signed bits, of algebraic degree 3(g-1). This is an ordinary constant restriction on the free raw core. It yields a semantic degree demand for the remaining affine-fiber family, not a new superlinear size bound. The earlier relative degree bound may be stronger; don't add degrees. The actual NP-completeness remains a uniform property of the containing family, not proof of a size lower bound.
