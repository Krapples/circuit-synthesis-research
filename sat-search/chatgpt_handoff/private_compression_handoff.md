## 1. Exact abstract dictionary cover

Let t independent payloads take values in [P], P=2^ell, with arbitrary shared Boolean dictionary h and independent slot selector j. The target h(x_j) is the existing unit-mode single-slot dictionary subfamily of the switchable grammar. Suppose a prefix has c data frontier bits and its q-bit ingress code depends only on h, not j. Each code determines a fixed map on the data. From the previous product-of-partition-sizes theorem, the set of dictionaries assigned to a realized code is constant on the cells of a partition of [P] into at most r=min(P,floor(2^(c/t))) classes. If r<2, nonconstant dictionaries are impossible. If r=P, zero ingress bits suffice abstractly (keep every data bit).

For 2<=r<P, each code accommodates at most 2^r-2 NONCONSTANT dictionaries, since both constant dictionaries are among the 2^r functions constant on those classes. Therefore
    2^P-2 <= 2^q (2^r-2).
The ratio is strictly greater than 2^(P-r) and at most 2^(P-r+1). Consequently q>=P-r+1. This is one stronger than the earlier elementary cell-count floor. It is EXACT for abstract encodings: reserve r-2 distinguished domain points as singleton classes; partition the remaining P-r+2 points into two classes according to h's value, identifying a bipartition with its complement, including the trivial partition. At most 2^(P-r+1) choices of partition occur. Encode its index in q=P-r+1 bits. Given it, encode each x_j by its class, using a joint mixed-radix code of width ceil(t log2 r)<=c. The decoder, supplied h,j, reads h at any representative of the selected class. The encoder can be arbitrary Boolean functions; no efficient gate implementation of this abstract upper bound is claimed. In particular for one slot, c<ell and c>=1, exact q=P-2^c+1. If c>=ell no ingress needed in the one-slot abstraction, and c=0 is impossible. The complement identification does not require transmitting the actual h value of a class since the decoder receives h.

## 2. Private-region decomposition and local floors

Take a live proper signed AIG with all D=t ell essential payload primaries, t>=2, and arbitrary query-only metadata. Can use the original full SAT graph with designated physical inputs, or a simplification under common constant restrictions preserving all relevant contexts. Signed wires free, syntactic ancestry; remove trivial constant and alias gates and dead gates. The output is mixed. Each gate is either metadata-only, private to one slot (its nonempty set of payload ancestors lies in that slot), or mixed (ancestors in >=2 slots). These are disjoint classifications of original gate IDs. Let B_i count private gates of slot i. Let c_i count distinct underlying private signals (including raw payload primaries) read by mixed gates; necessarily c_i>=1. All live private gates lead to such ports. Let Q_i count metadata-only operand OCCURRENCES into those private gates, and q_i count distinct such sources. Each private gate has at most one such operand.

Fix selector to i and other payloads arbitrarily, vary all P dictionary bits. The private port tuple for slot i depends only on that slot and its q_i metadata sources; all downstream dependence on x_i passes through its ports. Other private cones are independent of x_i. Thus a fixed vector of metadata values determines a fixed port map, and every dictionary in that vector's cell must be constant on its fibers: equal port tuples imply identical output with the same dictionary and other inputs. A c_i-bit tuple has at most 2^c_i image values. Apply Section 1 with t=1:
    Q_i>=q_i>=L_i, where L_i=P-2^c_i+1 if c_i<ell, otherwise 0.
Even sources depending on selector and other metadata are permitted; selector fixed to i, and any remaining source is a function of h in that context. We do not require independence of the sources. A stronger implementation-specific count can discard sources constant across h, or use actual log code count. A given metadata source may feed several private regions; its separate first-reader gates/operand occurrences in those regions are distinct, and each private gate has at most one metadata operand. Hence sum_i L_i is a VALID disjoint charge, NOT a sum of overlapping arbitrary cone sizes.

Within each slot the dictionary supplies AND/OR cofactors for every pair, keeping other slots and payload bits fixed. The multiport first-branch theorem applies to its private DAG (all data paths exit through its c_i ports) with outside data fixed. Thus B_i>=ell-c_i+max(0,ell-c_i)+L_i. Let M count mixed gates. Every mixed gate except output has at least one mixed successor, and each private port enters some mixed gate. Counting mixed slots yields 2M>=M-1+sum_i c_i, hence M>=sum_i c_i-1. Adding the disjoint regions proves for the basic selector promise
    B_D >= D-1+sum_i [max(0,ell-c_i)+L_i].
No cross-slot pair completeness is assumed for the selector function alone.

## 3. Stronger full switchable SAT ledger

The full switchable incidence promise contains BOTH the dictionary selection contexts above AND the cross-slot AND/OR cofactor witnesses of pair_cofactor_branch_handoff.md. Use the SAME original topology and same designated data coordinates in all these contexts (only fix constants common to the family, not the mode or selector). Thus for all D bits, total excess data/internal fanout e>=D-1 by first-branch separation. Exact global ledger B_D=D-1+Q+e, where Q counts all metadata operand occurrences into data-dependent gates. Q>=sum_i Q_i>=sum_i L_i. Consequently
    B_D>=2D-2+sum_i L_i.
Also Q>=ceil(log2 R) for any certified number R of residuals across the full independent metadata domain. Take MAX of ceil(log2 R) and sum_i L_i, not their sum; both constrain Q. The previous programmable graph/dictionary residual counts apply. Do not add the local e bounds to global e>=D-1 as they may overlap. All counts are on one exact graph, with distinct gate IDs. If using a common restriction, surviving counts lower bound original count; private status may change under restriction, so do not assert private classifications of the unrestricted DAG from a specialized slice without checking ancestry there.

## 4. Conditional superlinear architecture obstruction

Let Z=#slots with c_i<ell. For each such slot L_i>=P/2+1. Therefore Z(P/2+1)<=B_D (indeed <=B_D-2D+2 in the full pair-complete promise).
Use the existing switchable packing with m=2^k triple groups, t=3m, ell=floor(k/4), P=Theta(m^1/4), n=Theta(m log m), D=Theta(n) along these lengths. If a fixed positive fraction of slots privately compress, Z=Omega(m), then
    B_D=Omega(m P)=Omega((n/log n)^(5/4)).
This excludes O(n^1.01) circuits within that specified architecture. Conversely if B_D=O(n^1.01), then
    Z/t=O(m^(-.24) (log m)^1.01)=o(1).
Almost all slots must expose at least ell distinct private ports to the mixed region, so M>=ell(t-Z)-1=(1-o(1))D. More generally with ell=floor(alpha k) for fixed 0<alpha<=1 in the same layout, n=Theta(m log m), fixed fraction compression gives Omega((n/log n)^(1+alpha)); for s=O(n^(1+epsilon)), epsilon<alpha, fraction is O(m^(epsilon-alpha)(log m)^(1+epsilon)). No assertion that any unrestricted SAT circuit necessarily compresses this way; it can mix early or even route raw inputs to mixed gates. This is a restricted-architecture lower bound, not a numerical improvement on the best unrestricted SAT lower bound. The private-compression condition is purely topological, checkable on a candidate with designated physical slots. No new packing/padding replay. No guarantee of usefulness for 4-input native synthesis targets.

## 5. General block partitions and laminar accounting

Replace single slots by disjoint nonempty groups of slots. Private region for group U consists of gates whose nonempty payload support lies wholly within U; its outgoing data frontier includes bypassed raw primaries, and output if U is all slots. For arbitrary ingress, fixing selector to any slot in U and fixing other slots gives at least the one-slot floor L(c_U) when c_U<ell. If the ingress code is independent of selector within U for each fixed h, the exact abstract product bound gives a stronger floor: r_U=min(P,floor(2^(c_U/|U|))), impossible if r_U<2, floor P-r_U+1 for 2<=r_U<P, zero otherwise. With arbitrary mixed selector/dictionary dependence use previous threshold theorem restricted to the |U| selectors. Q(U) counts metadata operand occurrences in all gates supported inside U; it is at least each certified ingress floor for that group. Sources can depend on selector; use only the applicable hypothesis. All such local statements hold with the same data topology and arbitrary outside payloads fixed for the semantic proof.

For a fixed laminar tree of slot groups, assign each data-dependent gate to the smallest group containing its entire payload support (include root = all slots and singleton leaves). Then Q(U)=Q_local(U)+sum_(children V) Q(V), Q_local>=0. Given any certified local ingress floors F(U), the strongest lower bound on Q(root) from these count constraints ALONE is the tree recurrence
    W(U)=max(F(U),sum_child W(V)).
Equivalently maximum total floor over antichains of group nodes. Proof lower by induction and achieve the abstract relaxation with Q_local(U)=W(U)-sum_child W(V). This is not a circuit existence proof: abstract local integer counts may fail actual gate topology or semantics. It clarifies exactly how much can be added at multiple hierarchical scales without further constraints. Any disjoint group selection (antichain) charges disjoint private original IDs; nested groups cannot be summed. If earlier actual Q(V) known, a parent may require extra local occurrences max(0,F(U)-sum_child Q(V)); two lower bounds alone cannot be subtracted. For the full switchable promise combine W(root) with global e>=D-1 through the slot identity. This is a valid disjoint hierarchy, not a superlinear multistage potential theorem.

## 6. Controls and limitations

Selector-first upper construction selects each payload coordinate using a mux tree (or one-hot enabled bits), then evaluates the shared table only once. Each slot can expose ell private signals, no privately compressed slot charge. Dictionary-first evaluates every slot privately, yielding c_i=1 and the additive cost. Both are implementations of the simple selection promise only, not full SAT; neither refutes the architecture bound. The user-requested harder existential route must show that early mixing cannot satisfy all of the hard-mode constraints at small size, or force many independent compressed regions. No such theorem established here. The ordinary SAT circuit may simply mix every slot immediately; no argument from graph count, residual entropy, or the fact that the promise also contains NP-complete incidence rules that out.
