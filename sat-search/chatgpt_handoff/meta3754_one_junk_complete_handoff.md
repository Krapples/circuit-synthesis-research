## 1. Statement and structural setting

For a bipartite C4-free simple graph G, suppose C is a minimum-size fan-in-exactly-two monotone AND/OR circuit computing its edge function F, and an implicant-lift fixed point. Then C cannot have exactly one AND gate not pointwise below F.

Assume such a unique junk gate J exists. Use Section 2 of the preceding handoff: all gates live; no gate semantically equivalent to an earlier wire; no AND reads a clean wire (replace by that wire, preserving F and decreasing size); no dirty OR reads a clean wire (lift fixed point); clean region consists of clean AND tops and an OR collector tree of exactly T-1 gates. No raw input is clean. Every gate is true on the all-one input, so the existence of J and computation of F entails a nonempty graph. The zero-vertex/empty-graph case cannot have such a circuit with junk. Every pure disjunction gate has support size at least two by semantic nonredundancy. Every pure OR support is nonempty. J is live and not the output.

Use notation O(S)=OR of raw inputs in S, O(empty)=0 only as temporary rewrite notation. Unique junk J=O(A) AND O(B), both supports nonempty; all dirty ancestors of J are pure ORs. If A subset B or vice versa, J equals one already available operand and is redundant. Exclude containment henceforth. Every top that reads J through OR paths has exactly one operand containing J in its OR closure (otherwise its value >=J, impossible for a clean top). It has form
    K=(J OR O(D)) AND O(C),
where C nonempty, D possibly empty, all supports raw. D is the union of leaves other than J in that OR closure. Each of J*O(C), O(D)*O(C) is clean. Other tops are pure disjunction products. All top readers of J are of this form, and at least one exists. Use U for union of their opposite supports C (or restrict to a particular carrier's descendants). All replacements below preserve all old raw contributions O(D)*O(C) unless explicitly covered by surviving output, never accept a negative input, and preserve every edge input. This suffices for equality to F by monotonicity. Temporary zeros simplify to aliases/dead pruning, and final nonconstant F needs no constant gate.

In a C4-free graph, any set of at least two distinct vertices has at most one common neighbor. In a bipartite graph a nonempty clean pure disjunction product O(S)*O(T) has disjoint supports and all cross pairs edges; in particular S,T each homogeneous in opposite bipartition classes. We use both facts throughout.

## 2. Shared provider filtering lemma (actual OR DAG, not formula unfolding)

Let O(S) be a pure OR provider cone. Keep fixed an existing set of other uses of some nodes in that cone, and call a node protected if it must remain unchanged for those uses; take ancestor closure. Raw inputs always available. Suppose every protected OR node with support R has R contained in N(d) for some vertex d. Then to construct O(S intersect N(c)) for any specified vertex c, no more new OR gates are needed than the number of UNPROTECTED original OR nodes in the cone. Indeed for each protected node R: if R subset N(c), reuse it; otherwise R intersect N(c) has size <=1 (because d != c and C4-free). Supply that single raw input or zero. At each unprotected OR gate compute union of the filtered child outputs, using at most one gate, or an alias/zero. Do not change any protected node. Topological order inherited, no duplicate cost. This permits reusing old exclusive IDs as modified gates. If the root is a raw input the claim is immediate.

A second filter is used when S subset N(c), a distinguished leaf a in S is to be removed, and every protected OR node containing a has ALL its c-R edges already covered by retained computations. If root is unprotected and O(S) has a gate, rebuild its exclusive part, setting a and protected nodes containing a to zero whenever read by an exclusive node. Keep protected nodes unchanged elsewhere. The new provider O(S') may drop other vertices only if their c-edges were already covered. It omits a. At least one exclusive OR unit disappears: along a path from raw a to the unprotected root, the first exclusive gate reads either a or a protected node containing a and thus receives zero. If S' empty, no star required; otherwise it is a valid raw/OR provider. No other live use is changed by the rewrite. Use this only when the dropped central edge c-a is already covered or will be restored by another star, and when a missing noncentral c-edge ensures nonempty S'.

Two ways to select the protected nodes:
(A) After setting J=0 and simplifying the residual circuit, keep all pure OR nodes still needed for its clean pure top products. A protected OR node R lies in a pure operand of some such top, so R subset N(d) for some opposite vertex d. (One can retain syntactically live original pure nodes, not apply arbitrary semantic resynthesis that would obscure IDs.)
(B) Keep the original top/OR-carrier network and replace J at its use sites; protect pure OR nodes on paths to the output avoiding J, and their ancestors. Such a node reaches a first top in an OR closure along that path. It is either in a pure top operand, in the raw contribution D of a J-containing operand, or in its opposite C. In the first two cases its support R lies in N(d) for some raw opposite vertex. In the third case C need not form a clean product with a nonempty raw D (D can be empty), so DO NOT assume the general filtering lemma in that case without additional reasoning. In the overlap arguments below, C is singleton or is confined to one color and excludes the intersection vertex; those facts eliminate the problematic protected uses. This explicit distinction is needed for sound accounting.

## 3. Overlapping operand supports: all readers allowed

Write I=A intersect B, nonempty. For each v in I, J accepts singleton v, so cleanliness of J*O(C) implies C subset N(v) for every top reader. Hence U subset intersection of N(v) for v in I. In particular C never contains any vertex of I.

### 3a. |I|>=2

U is a singleton {c} by C4-freeness and existence of a reader. All opposite C equal {c}. Select S=B if c in A, S=A otherwise. (c cannot be in both.) On any edge accepted via J*C, one endpoint is c; if c in A the other endpoint lies in B; if c in B it lies in A; if c outside both it lies in I. Thus every such edge is covered by x_c*O(S intersect N(c)), a clean star.

Replace J by R=O(S intersect N(c)) at ALL its uses, keeping the raw OR carriers and tops. Construct R by the filtering lemma using protection scheme B. Every protected OR node has support size >=2 and cannot occur in the opposite C of a J-dependent top, since C={c}. All other protected occurrences are in a clean raw product, hence meet the lemma's hypothesis. Rebuild only unprotected nodes of the chosen original operand cone, retain all other protected computations. Retaining or pruning the unused other J operand cone cannot increase the total original OR budget; if it has shared uses, those nodes are protected. Each new top is clean: for J-dependent tops it is x_c*(R OR O(D)), whose two terms are clean. Every old accepted edge remains accepted. Delete J without adding any units beyond the available exclusive OR budget. Strict saving >=1.

### 3b. I={a}

Every C subset N(a). A vertex c in U intersect (A minus B) is adjacent to ALL of B by testing the pair {c,b}; similarly c in U intersect (B minus A) adjacent to all of A. Each type has at most one exposed centre (both supports size >=2 after excluding containment). Both types cannot coexist: both centres would be adjacent to a and hence same bipartition color, yet would have to be adjacent to each other. Thus at most one additional exposed centre c exists.

If none, every edge accepted via J*C touches a (any edge avoiding a accepted by J would cross A minus B and B minus A, and its C endpoint would be an exposed centre). Replace J by x_a at all sites, which keeps all those edge contributions and is safe because C subset N(a). Strictly delete J.

Otherwise WLOG c in A minus B, all B subset N(c), a in B. Thus A contains adjacent a,c (mixed color), and B is homogeneous. Replace J by x_a at all sites. The only possibly lost edges are in star c-B; all edges through J involving a still covered by x_a*O(C). Use protection scheme B. A root cannot have any use avoiding J: its support is mixed color, so cannot occur in a nonempty clean raw product, or in an opposite C subset N(a) homogeneous. Delete A root (distinct from J, B root; A and B incomparable). If B root has a protected use, its support contains a so cannot be in C subset N(a); it is in a clean raw product, whose opposite support is exactly {c} by uniqueness of common neighbor. Thus all c-B edges already covered by the retained raw contribution. No new star needed. Same argument applies to any protected OR node in B cone containing a (support size>=2, c is its common neighbor). If B root unprotected and some c-B edges still missing, trim B by the second filter with distinguished a. Edge c-a is already covered: an exposing top has c in its C, and J was replaced by a. Every dropped protected node's c-edges already covered. At least one additional exclusive B OR gate deleted; the surviving B' is nonempty if a missing noncentral edge needs rescue. Add x_c*O(B') as a clean star and OR to output (<=2 new gates). At least J, A root and one distinct exclusive B OR removed (>=3). A root is not a B ancestor because A mixed and B homogeneous. All protected uses retained. Strict saving >=1. If no edges missing, simply delete J (and any dead nodes). This completes all overlap cases, regardless of number of OR readers.

## 4. Disjoint supports with a singleton operand

WLOG A={a}, B disjoint; containment already excluded. J=x_a*O(B) dirty, hence B contains a nonneighbor of a. Any C containing a would accept all a-B pairs including nonedge, impossible. On edge inputs every J-dependent contribution is an a-b edge with b in B intersect C intersect N(a).

Set J=0 and simplify. The only missing edges lie in star a-(B intersect N(a)). If none missing, delete J. If there are at least two distinct immediate readers of J (AND or OR), at least three distinct units J and these readers disappear. Build O(B intersect N(a)) by filtering lemma with protection A, retaining residual gates and using at most original exclusive B-cone units. No immediate reader or J is inside the B cone. Add one clean star and one OR collector gate (<=2). Strict saving.

If sole immediate reader is an AND, it is a clean top. Remove J and that top; replace top by the filtered star, using protection A (any originally unused opposite provider need not be retained). Reuse collector with leaf replaced; if the star unnecessary prune. Two removed, <=1 new AND; filter costs no extra. Strict saving.

If sole immediate reader is OR, write H=J OR O(D0), where D0 nonempty and pure. In fact its other operand cannot have J in its OR closure, since then H would alias that other operand, contradicting leastness. D0 cannot contain a, since H would alias O(D0) (J<=x_a). Every top reading J passes through H, so its raw support D contains D0. If some J edge contribution exists, choose its endpoint b in B intersect C intersect N(a). Every d in D0 is adjacent to b by the raw clean product; d has a's color and d != a. Every opposite C of every J-dependent top is homogeneous in b's color, since it must be adjacent to D0. Any useful b' from any reader is a common neighbor of a,d, hence b'=b. Only one useful edge.

If B homogeneous, it has b's color and includes a nonneighbor b0 of a. For every c in every opposite C, J*C accepts assignment with a,b0,c all true (repetitions permitted); b0,c same color and a-b0 absent, so a-c must be edge. Thus replacing J globally by x_a is safe, preserves every old accepted edge, and deletes J strictly.
If B mixed, B root cannot occur in any remaining pure top after J=0. It is an actual OR gate since mixed implies >=2 vertices. Delete J, H and B root, then append just the clean edge a-b and an OR (<=2 gates). Residual pure tops unchanged; no need to reconstruct B. Strict saving. If there is no useful J contribution, deletion alone suffices. All singleton cases complete.

## 5. Disjoint large supports: exposed stars and deletion budget

Now A,B disjoint, each size>=2. From previous handoff, at most one exposed a in A intersect U, universal into B, and at most one exposed b in B intersect U, universal into A. J-dependent edge contributions exactly the union of available stars a-B and b-A. Set J=0, simplify, and choose a MINIMUM subset of these at most two stars that covers all missing edge inputs. Let k be its cardinality. If k=0 deletion suffices. For k=1 and >=2 immediate readers, remove J+readers (>=3) and add one star+collector (<=2), retaining its original pure provider; strict. All direct-AND-only cases were proved in Section 5 of meta3754_one_junk_handoff.md; in particular sole direct reader and k=2 saves its opposite mixed OR root and one exclusive provider gate. That proof used the exact same structure and no assumption about this turn's new results.

### 5a. Sole immediate reader is OR, disjoint large supports

As before H=J OR O(D0) with nonempty pure raw D0; if other operand contained J, H would alias it. Every J-dependent top has D containing D0. If both exposed centres a,b exist, A and B homogeneous opposite colors; D0 would have to be adjacent to both a,b, impossible. Thus exactly one exposed centre a WLOG (if none delete J). B homogeneous opposite a; because some top C contains a, D0 has B's color and every opposite C has a's color.

If A root not used in the J=0 residual, delete it as well as J,H and add a-B star with existing B provider and one collector (<=2). Disjoint support ensures A root not inside B cone. Strict.

Otherwise A root is used by a pure top in residual, hence A homogeneous a's color. Define V={b' in B adjacent to ALL of A}, |V|<=1; B minus V nonempty. For each b' in B minus V pick u in A nonadjacent b'. Every c in every opposite C has a's color, so J*C on {u,b',c} forces b'-c (u,c same color, u-b' absent). Hence all C subset intersection of N(b') for b' in B minus V. If this set of nonuniversal b' has >=2 elements, then C={a} (a is already their common neighbor). J can be replaced by full O(B) at all sites, safely preserving all J-contributed pairs; delete J. If B minus V has size1, since |B|>=2 necessarily B={b',b} with V={b}; all C subset N(b'). Replace J by raw x_b'. This may lose only a-b among J-dependent accepted edges. But because A root used in a residual pure top, its opposite support must equal {b} by uniqueness of common neighbor of A. Thus a-b already covered. The new tops are clean and all edges retained. Delete J. This completes the sole-OR case.

### 5b. Two stars necessary; >=3 immediate readers, or two readers at least one AND

k=2 implies both centres a,b exposed and each star has a noncentral edge not covered by residual or the other star. A and B homogeneous opposite classes. Neither root can be protected in residual: if A root is used in a pure top after J=0, its opposite support must equal {b} and all b-A edges covered, contradicting necessity; symmetric for B. In A cone, every protected OR node containing a is used by some residual pure top, whose opposite support is exactly {b} by common neighbor uniqueness. All its b-edges are already covered. Trim A using second filter, protection A (residual), distinguished a; the central edge a-b covered by the FULL a-B star. This saves one exclusive A OR unit, distinct from J and its readers, while preserving all required b-A noncentral edges. B cone cannot share A-cone OR nodes (disjoint supports). Use new stars a-B and b-A' with <=4 new gates including collector, <=3 if residual output zero.

If >=3 immediate readers, remove J, those readers and one exclusive A OR => >=5 units, strict. If exactly two immediate readers and at least one AND, remove J, both readers and one exclusive A OR => >=4. If residual output zero add <=3, strict. Otherwise the vanished direct clean AND top also removes at least one old collector OR (collector tree with nonempty remaining leaf set), independent of all those units. Remove >=5 add <=4, strict. If sole direct reader refer to prior proof. This exhausts all such budgets.

### 5c. Last case: exactly two immediate readers, both OR, k=2

Write H1=J OR O(D1), H2=J OR O(D2). Each D_i nonempty pure by nonredundancy (if other operand contains J, alias). Each top reading J is reached through at least one H_i and has D containing that carrier's raw support. Since both exposed centres a,b are opposite colors, no carrier can reach tops exposing both (otherwise every d in D_i adjacent to both a,b). As both stars necessary, reorder carriers as H_a, H_b, each reaches at least one top exposing its indicated centre. D_a has B's color, so ALL opposite C of tops reached through H_a have A's color. Symmetric for H_b. No top can be reached by both carriers (would require its nonempty C adjacent to both opposite-color D supports). These reachability statements also hold for paths through shared OR nodes.

Claim full provider replacement J -> O(B) in H_a is safe for EVERY top it reaches. As in 5a, all C subset N(b') for every nonuniversal b' in B (using A homogeneous). If |B|>=3 there are >=2 such b', so every C={a}. The same holds if |B|=2 and no universal, but here b is universal. Thus only possible unsafe situation is B={b,b'}, where b' nonuniversal, some top C contains c not adjacent b, and c != a. We have c adjacent b', and a adjacent b'. The nonempty D_a must be adjacent to both a and c, since at least one top exposes a and another (possibly same) contains c. By C4-free uniqueness D_a={b'}. The raw product at a top containing a then ALREADY accepts edge a-b' even after J=0. Its only other star edge a-b belongs to the b-A star. Consequently a-B star is unnecessary given residual and b-A star, contradicting k=2. This proves the claim. Symmetric full provider replacement J -> O(A) in H_b is safe as well.

Perform the two operand rewires in place, using earlier original providers, delete J. Each affected top's raw contribution stays; its new provider product with C is clean by the claim. Every originally J-contributed edge is an a-B edge along the a carrier or b-A edge along the b carrier, and the corresponding replacement preserves it. Other tops untouched. No new gates; strict saving at least one. This is the final configuration.

## 6. Conclusion and proof status

Containment, overlap, singleton and disjoint-large configurations exhaust A,B. Every one yields a smaller exact-model circuit computing F, contradiction. Therefore no minimum lift-fixed circuit on a bipartite C4-free graph has exactly one junk AND, which proves the hone premise of R_meta_3754_1 on paper, subject to audit. With zero junk the result immediate; >=2 junk gates remain open in this analysis. In particular this does NOT prove L-meta-3754 itself, the many-junk premise, unrestricted signed-circuit normalization, or an SAT lower bound. Equal-size transformations were not used to conclude universal cleanliness. No production changes or upstream PR.
