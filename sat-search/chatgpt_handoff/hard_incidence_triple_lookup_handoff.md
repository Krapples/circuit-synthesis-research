# Movable hard-incidence triple lookup: quadratic support-asymmetry demand

Date: 2026-11-26. Starting master b49438f3ca87ea39ee287b76b8655a9fd2c8eb6f. Extends mixed_support_asymmetry_handoff.md and switchable_incidence_handoff.md. New fixed-metadata 3-CNF incidence subfamily with arbitrary placements of address and table coordinates; quadratic weighted original-gate demand, robust source-selectable routing and first-large-support triple reserve. All paper proofs, finite regression, no independent audit, Lean verification, native change or unrestricted superlinear lower bound. L-clb-036 remains open.

## 1. Exact existential construction

Use the switchable paired SAT layout with m=2^k groups, t=3m payload slots, ell=floor(k/3), P=2^ell, b=ell-4>=1, A=2^b=P/16, H=A^3. In particular H<=m/4096, H=Theta(m) as k grows, and H+A+4<=m for sufficiently large k. Existing tag-1 complementary witness indices encode signed literals: index 2v is positive v, 2v+1 is negative v. Set ALL metadata fixed to hard mode p=0, tag 1 for every programmable literal, positive physical signs, unused dictionary all zero. No dictionary sign or other metadata bit varies in this construction. The programmable logical clauses are then disjunctions of three signed witness indices. Use variable indices
    a_i=i, b_j=A+j, c_k=2A+k, d_k=3A+k (indices i,j,k in [0,A)), f=4A.
These fit in the P/2 available unforced witness variables, since P/2=8A. Here b_j and c_k denote variable names, not the integer b and scale parameter k.

Choose ANY three slots from distinct groups as address slots, and assign them the three dimensions in any fixed order. Choose ANY H distinct other groups, one slot in each, bijectively assign them the H table cells. Reserve A+1 other groups for pinning f=false and every d_k=false, using repeated negative literals in each pin clause. In each address group, use the selected slot for a positive literal a_x, b_y or c_z respectively, and the two remaining slots for positive f. These clauses force the selected witnesses true. The low b index bits of the chosen witness are precisely the b physical payload digits at coordinates 1,...,b (zero-based, coordinate 0 is sign); upper index bits fixed by block, sign bit zero.

For cell (i,j,k), put the two literals NOT a_i, NOT b_j in the other two slots of its chosen group. The designated table slot contains either NOT c_k if h_ijk=0 or NOT d_k if h_ijk=1. The witness indices c_k and d_k differ exactly in index bit b; their signed-literal indices differ exactly in payload bit b+1. This is a SINGLE physical low identifier digit, with the actual bit equal to h_ijk (c block 2A, d block 3A). This switch uses no extra per-cell variable or extra clause. When h=1 the clause is a tautological constraint under the fixed d_k=false pin, otherwise it forbids the selected three witness variables all true. All unused groups are (f,NOT f,f), a tautology.

For every h and x,y,z the physical word is legal, and its SAT verdict is exactly h_xyz. If that entry is zero, the corresponding forbidden triple conflicts with the three forced positives. If it is one, set exactly the three selected a/b/c variables true, every other a/b/c and all d and f false. Every forbidden triple other than the selected one has at least one false variable, the selected clause is inactive, and all pin and address clauses hold. Complementary-witness and guard extensions exist by the switchable grammar theorem. This is an exact ordinary constant projection from the existing NP-complete fixed-metadata incidence function to a movable three-address lookup, not a reduction with duplicated or complemented free physical bits.

The total paired length is still n=Theta(m log m), since ell=floor(k/3) and P=o(m); use exact length formula from switchable_incidence_handoff.md. The physical coordinate set for the t slots is unchanged across every choice of role placements at fixed m,ell. Pin clauses and other metadata are constant for each projection, but need not have the same payload values across different placements. This is allowed: the same fixed-metadata incidence circuit must be correct on ALL such payload assignments. No new padding proof or claim of improved encoding constants.

## 2. Triple ingress and routing theorem

Take the live proper binary-gate DAG of a SAT circuit or the actual simplified circuit obtained by fixing the hard metadata above. Use stable original IDs and syntactic support sigma(v) = set of designated payload SLOT ancestors. If applying to the original graph without simplifying, treat fixed metadata as constants in semantic evaluations. No restriction-specific ancestry change is needed. For any triple T of slots belonging to distinct groups, call a vertex T-dependent if sigma(v) intersects T. Define D_T as the set of distinct underlying independent side vertices at gates with exactly one T-dependent operand; I_T as the number of such gate occurrences. The output is T-dependent because each slot is essential on a suitable lookup context. For any fixed choice of source placement in Section 1, leave only the address bits in T and H table bits free. Every D_T value is independent of the addresses. Its tuple as a function of h must distinguish every table: the T-dependent DAG can be evaluated from address inputs and this side tuple, and different tables differ on at least one address. Thus
    |D_T| >= H, I_T >= H.
This is a residual argument about H independent PAYLOAD bits in the hard slice, not the P dictionary metadata bits of the earlier theorem.

Stronger: in the induced no-T-ancestry subgraph, for ANY chosen H source groups outside the three address groups, and ANY chosen slot in each, there are H vertex-disjoint paths from the physical payload bit b+1 of those slots to distinct D_T vertices, extendable by one edge into distinct T-ingress gates. Proof: for this placement all H source bits are independently free and other nonaddress inputs fixed. Any directed vertex cut from these sources to D_T supplies its values as a code for the side tuple, hence must contain >=H vertices. Apply vertex-capacitated Menger, including unit capacities at sources and sinks and allowing a zero-length path if a source is a side port. Pin and dummy groups can always be placed in the remaining m-3-H groups by H+A+4<=m. Every side source and every preceding vertex on the paths is syntactically independent of T, even before the projection. Endpoints of extended paths are distinct because a T-ingress gate has exactly one independent operand. Paths for DIFFERENT triples can overlap arbitrarily; no simultaneous multicommodity flow theorem is claimed.

Robust cut corollary: for any vertex set K of size k0<H in the no-T-ancestry graph, at most k0 nonaddress groups can contain a slot whose bit b+1 has NO directed path to D_T avoiding K (count a removed source as blocked). Otherwise choose k0+1 such groups, choose one blocked slot from each, extend to H source groups and arbitrary slots using spare pin groups. The H disjoint paths would include k0+1 paths meeting K, impossible. More generally any <=H specified source groups, one slot each, can be completed to a full placement and their chosen paths retained. This is a robust topological routing certificate in the actual hard-mode graph, not merely a count of global dictionary ports. It imposes no size bound on a shared routing core by itself.

## 3. Quadratic weighted demand on the mixed region

Let a(g)=|sigma(u) symmetric_difference sigma(v)| for the operands of g, as before. If g is counted by I_T, then T contains at least one slot in that symmetric difference: one operand has a T ancestor and the other has none. There are 27*binom(m,3) triples T with distinct groups. Any fixed slot occurs in 9*binom(m-1,2) such triples. Thus each gate is counted at most a(g)*9*binom(m-1,2) times (union bound, possibly loose). Summing I_T>=H over triples yields exactly
    sum_g a(g) >= m H = m A^3 = Omega(m^2).
No overlapping gate-complexity bounds are added; this is one weighted ledger with a proved capacity per gate. For the earlier selector-only construction at ell=floor(k/3), the weighted floor tP is Theta(m^(4/3)), strictly smaller asymptotically. Compared with the previous illustrative ell=floor(k/4) bound it is Theta(m^(5/4)). The change of ell is permitted within the same switchable layout parameterization but corresponds to different physical lengths/coordinates; do not add the two bounds across those layouts.

Even stronger per-slot condition: D_T is contained in union_{i in T} D_i, where D_i is the independent-side vertex set for the individual slot. If a gate enters T, choose an i in T present in its dependent operand; its independent operand is also independent of i. Therefore sum_{i in T}|D_i|>=H. If three slots from different groups all have |D_i|<H/3 this fails. Consequently ALL BUT AT MOST SIX of the t slots have >=ceil(H/3) distinct independent-side vertices (and corresponding ingress gates). The exceptional slots can lie in at most two groups. This is much stronger than the earlier per-slot P bound in the hard-mode graph, and uses varying OTHER payloads rather than metadata. It does NOT mean that each slot alone can index all H bits with ell address bits; the per-slot obligation is structural and inferred from overlapping triple requirements. The ordinary gate count must still only be charged according to a(g).

If every gate has a(g)<=O(m^beta), then
    B_D>=Omega(m^(2-beta))=Omega((n/log n)^(2-beta)).
This excludes O(n^1.01) for every fixed beta<.99. This is a restricted-architecture superlinear theorem, considerably weaker in architectural assumptions than the earlier beta<.24 example, but it is not unrestricted.

Conversely suppose s=O(n^(1+epsilon)), epsilon<1. For any fixed delta>0 with 1-epsilon-delta>0, define wide gates by a(g)>W=floor(m^(1-epsilon-delta)). The total low-asymmetry slot incidence is <=Ws=o(m^2). All but o(m) slots therefore have low-asymmetry incidence <H/6, since H=Theta(m); excluding at most six other slots by the per-slot condition, nearly every slot needs >=H/6 distinct side sources entering at wide gates. Also total wide mass is Omega(m^2) and each gate capacity <=3m, requiring Omega(m) distinct wide gates. For epsilon=.01, W=m^.95 is one illustrative threshold (delta=.04). Unlike the earlier m^.20 threshold and Omega(m^.25) global wide gates, the new hard-mode slice demands almost linearly large support differences at linearly many gates. No inference that those gates have large semantic support in every context.

## 4. Triple first-large-support compression

For integer r in [2,t], low vertices have |sigma|<r, an ancestor-closed region; output high. For triple T let K_T be all distinct low T-dependent vertices read by high gates, p_T=|K_T|. It includes raw data primaries if applicable. Let D_T^lo be the independent side set at low T-ingress gates, I_T^lo their occurrences. Use the same projection as Section 1. A fixed side-code determines a fixed map from 3b independent address bits to p_T-bit port values. If two addresses have the same code under this map, every table in this side-code cell must agree there. A map with <=2^p_T distinct values permits <=2^(2^p_T)-2 nonconstant tables, since both constants are counted separately. For p_T<3b this yields
    |D_T^lo| >= H-2^p_T+1 >= H/2+1.
p_T=0 impossible by essentiality; use bound zero for p_T>=3b. The same separator argument yields that many vertex-disjoint routes in the low no-T region from any chosen table source placement to the low side set, when the lower floor is positive. This is a compression bound for the JOINT frontier, not the sum of three per-slot minima.

Let Z_r count triples with p_T<3b. Each low gate is counted by at most a(g)*9*binom(m-1,2)<= (r-1)*9*binom(m-1,2) triples. Thus
    Z_r*(H/2+1) <= 9*binom(m-1,2) * (r-1) * |G_low|.
Divide by total triples 27*binom(m,3)=m*9*binom(m-1,2):
    Z_r / #triples <= (r-1)s / (m*(H/2+1)).
For s=O(n^1.01), r=1+floor(m^.95), this tends to zero. Almost every triple must retain at least 3b distinct T-dependent signals before the first region of that support size. The port tuple can still depend on metadata and other payload bits. This does not prove simultaneous injectivity for every triple under a single common context, or bound overlap of their ports. If many slots individually expose <b ports, all triples chosen from those slots have p_T<=3(b-1), so the preceding conclusion also implies all but o(m) slots expose >=b ports at this threshold (discard same-group triples, whose fraction is negligible). This improves the threshold scale, though b=ell-4 rather than ell. The older dictionary theorem remains applicable at its own threshold on this same ell choice.

## 5. Barrier: even the entire movable-role lookup subpromise is easy

There is an explicit O(m ell) signed AIG for the union of ALL placements and table/address values in Section 1, with fixed namespaces and fixed A. It is not a circuit for the entire hard incidence language.

Extract each triple's three signed indices (fixed physical positions). Classify the three unique address groups by two positive f fillers and one positive literal in the respective a/b/c block, OR their low b address bits across groups to recover the selected indices. Each group is checked with constant block/sign/f tests and O(ell) gates, trying all three positions, so O(m ell). A table group consists of three negative literals, one in a block, one in b block and one in c/d block. The pin groups have repeated d or f, and the tautological inactive groups contain f, so none is mistaken for a table cell. For each table group extract the three low address indices regardless of literal order, compare them to recovered addresses, and output its d-block toggle if all match. OR over groups; exactly one matching table group exists on the promise. Every operation can be implemented in O(ell) binary gates per group, hence O(m ell)=O(n) overall. No extra placement metadata is supplied. This gives a genuine analytic upper construction for the union of movable placements, not just one fixed placement. Consequently a method using ONLY the new lookup constraints cannot prove an unrestricted superlinear lower bound: this linear-size evaluator must satisfy all of the derived structural conditions (and can have wide asymmetry). The full fixed-metadata NP-complete incidence function includes arbitrary other clauses and has no such upper bound established here. In particular the theorem does not settle L-clb-036.

## 7. Scope and next step

New result is unconditional quadratic WEIGHTED demand on any correct hard-mode DAG, with robust per-triple routing from arbitrary other payload group choices, and stronger conditional ordinary lower bounds. It has an explicit linear-size promise evaluator, which is a useful negative control and demonstrates the need to use other existential instances. No new unconditional unrestricted superlinear SAT size bound. No production changes, new grammar padding or Lean verification. A next candidate is to generalize from a single triple lookup to a conjunction of many selected existential witness constraints with overlapping variable choices, and identify information that must coexist rather than be selected once. Beware that merely programming a larger explicit truth table still allows lookup and that shared routing across restrictions need not imply distinct gates. L-clb-036 remains open.
