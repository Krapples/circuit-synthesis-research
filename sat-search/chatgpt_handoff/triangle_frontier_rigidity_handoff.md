## 1. Model

Use precisely the previously proved fixed-coordinate triangle SAT restriction, n=Theta(A^2 log A). Set N=A^2 and identify Z, transposed as required, with a subset of [N]. Let P(X,Y)=X*Y denote Boolean matrix multiplication, a bit vector of N entries. Triangle is ND(P,Z)=1 iff P intersects Z. All 2^N possible products occur by X=identity, Y arbitrary.

A topological data prefix contains X,Y primaries and retained gates with X/Y ancestry. Its c-bit data-dependent frontier includes bypassed X/Y primaries if needed. Its q distinct data-free ingress signals determine a code a(Z) of at most q bits; after common constant restriction only Z varies outside the X,Y data. All paths from X,Y to the output pass through the frontier, and a fixed code determines a fixed frontier map E_a(X,Y). The suffix can use all Z, with arbitrary computation. The results are about distinct underlying bits, signed phases absorbed in fixed functions. They do NOT count a mixed X/Y/Z vertex as a Z-only code source, and do not assume an arbitrary non-topological cut admits this decomposition. We first use no restrictions on Boolean gate functions.

## 2. Exact cell count lemma

For a nonempty family H of subsets of [N], let r(H) be the number of distinct vectors
    (1[z subset S] : z in H), as S ranges over all subsets of [N].
These are the truth patterns of DISJOINTNESS queries in H on all possible product masks (S=complement of product); ND complements all bits, leaving pattern count unchanged.

For each z in H, choosing S=z yields a distinct principal lower ideal of H: {w in H:w subset z}. Indeed equality of two principal ideals implies both inclusions of their generators, hence equality. Therefore r(H)>=|H|.
If empty set not in H, S=empty gives one additional pattern, the empty ideal, not any principal ideal. Thus r(H)>=|H|+1.
In fact r(H)=|H| iff H contains empty set and is closed under pairwise unions. Necessity of empty set as above. If equality, for any z,w in H take S=z union w. Its pattern must be principal, generated by some h in H. Since z,w in that ideal, z union w subset h, and h itself belongs to the ideal so h subset S, hence h=S. Conversely if H contains empty set and is union closed, each S induces a nonempty subfamily; its union is in H, contained in S, and is its largest member. Hence every pattern is principal and there are exactly |H|. This is a combinatorial equality characterization, not an assumption that arbitrary code cells are union closed.

## 3. Exact abstract q versus c

Let H_a={Z:a(Z)=a} be each nonempty code cell. For a fixed code, restrict X=identity and vary Y over all product masks. Identical frontier values must give identical answers for EVERY Z in H_a, since E_a is fixed and suffix gets the actual Z. Thus r(H_a)<=2^c. Exactly one code cell contains the zero query. It can have at most 2^c members; every other cell has at most 2^c-1. With at most 2^q realized codes,
    2^N <= 2^c+(2^q-1)(2^c-1)
         = 2^(c+q)-2^q+1.
This improves the earlier rank-only c+q>=N. c=0 impossible (a nonzero query has nonconstant residual). If c<N, q>=1 and the strict deficit forces c+q>=N+1. If c>=N, q=0 is possible at the abstract level. For 1<=c<N, exact abstract minimum q=N-c+1: send the actual first q bits of Z as the code, compute one bit OR_{j<=q} P_j Z_j and retain the other N-q product bits; the suffix ORs the saved partial answer with remaining product/query intersections. Frontier length 1+N-q=c. For c=N simply retain all product bits and no Z ingress. These are realizable Boolean maps but may need expensive prefix circuits to compute product bits. No gate-size upper bound proportional to the number of code bits is inferred. This is also an elementary two-round deterministic communication bound for set intersection, no novelty claim over communication literature.

In a live proper binary-gate prefix, d=2N, B=d-c+Q+e with Q actual data-free operand occurrences and e nonnegative excess fanout as in multiport_residual_reserve_handoff.md. Since Q>=q, for c<N the prefix has B>=3N-2c+1, a linear floor. Do not count prefix bounds independently across nested frontiers.

## 4. Tight width forces an exact encoding of the product

Set q=0,c=N. The code map E(X,Y) is independent of Z. Equal E values imply equal P values by unit Z queries. The product is surjective, and the code space has exactly 2^N values. Every distinct product must have a distinct nonempty code fiber, so every product has precisely one code; there is a bijection pi on the N-bit cube with E=pi(P). This does NOT by itself imply a cheap decoder for the individual P bits, a monotone pi, or ordinary gate lower bounds beyond linear.

Additional premise A: the vector E, in its chosen fixed port orientations, is coordinatewise MONOTONE in X and Y. Restrict X=identity. Then pi(Y)=E(I,Y) is a monotone bijection of the Boolean cube. A monotone bijection of a finite poset has monotone inverse: since it is a finite permutation, its inverse is some positive power of itself. Thus it is an order automorphism, fixes bottom, permutes the atoms and preserves least upper bounds. Hence pi is a coordinate permutation. Consequently the actual c frontier signals, up to their order, are the individual Boolean product outputs. No monotonicity assumption on suffix is needed for this conclusion.

Additional premise B (alternative): for each singleton Z query, the suffix is coordinatewise MONOTONE as a function of the N formal frontier inputs in their chosen fixed orientations. The suffix decodes each product bit; all 2^N codes realized, so these N monotone decoders together compute pi^{-1} on the entire cube. Apply the same order-automorphism argument to inverse. Again the frontier ports are product entries. Premise B says nothing about monotonicity of the prefix implementation. To use signed port orientations, choose them once consistently for all contexts. Semantic monotonicity of E does not guarantee monotone implementation. Likewise monotonicity only on reachable codes is enough here because every code is reachable, but at c>N this reasoning fails.

## 5. Transfer of the classical monotone BMM lower bound

Established external result, not new here: Paterson, Complexity of monotone networks for Boolean matrix product, TCS 1 (1975), 13-20; Mehlhorn and Galil, Monotone switching circuits and Boolean matrix product, Computing 16 (1976), 99-111. Survey statement https://www.mathnet.ru/links/c92409033c6252f6614292002c8c4edc/rm667_eng.pdf (Monotone Boolean functions, p.963), and lecture summary https://tcs.informatik.uni-bonn.de/lib/exe/fetch.php/teaching/ss19/lecturenotes3.pdf . These show the monotone fan-in-two AND/OR circuit for all A^2 entries requires at least A^3 ANDs and A^3-A^2 ORs. The weaker classical Pratt lower bound Omega(A^3) suffices here.

If the q=0,c=N prefix is implemented as a monotone AND/OR circuit in positive X,Y and consistently oriented ports, premise A holds, and it computes all product outputs. Its actual gates, without duplicating a circuit per output, therefore cost at least 2A^3-A^2 in the monotone gate model. This is Omega((n/log n)^(3/2)) on the encoded SAT slice. An unrestricted suffix cannot evade the prefix lower bound. In signed AIG terminology this applies to a prefix whose fixed orientations admit monotone AND/OR conversion at constant-factor cost (e.g. dual-rail conversion with only positive primary literals in relevant cones). Do not equate a semantically monotone function with a monotone implementation. This is a stronger restricted architecture condition than an entirely monotone full circuit, not a numerical unrestricted bound.

## 6. Optimized masking: necessary negation width for small exact-product encoders

Suppose q=0,c=N and either premise A or B proves the ports are product entries (up to fixed orientation/permutation), but the prefix is an unrestricted signed AIG of s gates. Convert the multi-output prefix to AND/OR with signed primary literals only using at most 2s binary gates by retaining both phases of each gate as required. In each output's unfolded formal accepting terms, the positive set of any term accepting a minterm is exactly that minterm: otherwise the term accepts a proper subset of it, contradicting minimality. For BMM each minterm has size two and there are A^3 output/minterm pairs. Define w as the maximum over these pairs of the minimum number of DISTINCT negative input variables in an accepting term on that minterm. It is a property of this specified converted multi-output circuit, not a count of inversion gates.

For a mask S of original X/Y variables, replace positive literals in S by 0, negative literals in S by 1, and negative literals outside S by 0, keeping other positive inputs. The resulting multi-output circuit is monotone and pointwise <=BMM, since acceptance on x implies original acceptance on x with S cleared, and BMM monotone. For each output/minterm pair choose an accepting term of negative width <=w. Randomly put variables in S independently with probability w/(w+2) (w=0 gives S empty). Its selected term survives whenever all negative variables are in S and both positives outside S, probability at least
    (w/(w+2))^w * (2/(w+2))^2 >= 4 e^(-2)/(w+2)^2
with the w=0 convention. This is an optimized version of the elementary mask argument in clique_incidence_negation_handoff.md; related bounded-negation-width conversion is established in Jukna and Lingas, Lower bounds for Boolean circuits of bounded negation width, JCSS 129 (2022), 90-105, https://doi.org/10.1016/j.jcss.2022.05.003 . No priority claim. Choose L=ceil((e^2/4)*(w+2)^2*(ln(A^3)+1)) independent masks; union bound gives a collection covering every minterm of every output. OR masked output copies separately for each of N outputs. The resulting MONOTONE multi-output circuit is exactly BMM, by minterm coverage and pointwise soundness, of size <=2sL+N(L-1).
Using the classical monotone bound gives
    (s+N)*(w+2)^2*log A >= Omega(A^3).
Thus if the actual prefix has s=O(n^1.01)=O(A^2.02 (log A)^1.01),
    w+2 >= Omega(A^.49 / (log A)^1.005).
In particular some product entry's minimal two-edge witness requires polynomially many distinct negative literals in EVERY accepting term of the specified converted prefix. The result does not imply that many distinct NOT gates, disjoint gates per term, or a superlinear unrestricted bound. It only applies when actual port functions are BMM (not arbitrary tight code bijection). The proof uses optimized mask probability and simultaneous coverage across all outputs, not independently summing minimum sizes. One could use more refined established negation-width results if verified; the above elementary inequality suffices.

The minimum-width no-Z-ingress condition is not proved necessary for small SAT circuits. Even within it, an arbitrary bijective product encoding can be nonmonotone, and a small circuit could conceivably avoid actually materializing individual product outputs by such an encoding. With more than N ports the rigidity proof fails. With early Z mixing the no-ingress premise fails. Raw X,Y bits as a 2N-bit frontier are an immediate counterexample to any unconditional matrix-product materialization claim. This is the next gap: derive a cost for approximate-width encodings or early Z mixing without imposing monotonicity or unjustified decoding cost.
