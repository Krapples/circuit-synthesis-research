## 1. Model and sole-reader domination obstruction

Count ordinary proper binary Boolean gates (B2, all ten truth tables depending on both operands), with constants, signed wires/NOT and fanout free. This is NOT the earlier XOR-AND multiplicative complexity model: XOR is a counted proper binary gate here. Restrict to the live output cone, simplify constants, identical or complementary operands, and unary/constant gates by signed aliases. For each original data input x, its readers are distinct remaining gate IDs with x as a direct operand, ignoring phase. Query-only gates, having no syntactic data ancestry, may be treated as arbitrary free functions of the query for this lower bound; all data-dependent binary gates are counted. Syntactic ancestry is taken in the live graph, not merely semantic dependence. Query domain is common and independent of the full data cube. An essential data bit has at least one reader unless the output itself is that raw bit, which is impossible if another data bit is essential.

**Lemma (sole-reader domination).** Suppose x is essential at some allowed query, and at another allowed query q* the output is independent of x but essential in a different bit y (with all other data fixed suitably). If x has a sole reader g, g cannot intercept all directed paths from y to the output.

Proof: g reads signed x and some other signal h, with h independent of x (acyclicity and x's unique reader). Fix q* and all data other than x,y so the output changes when y flips. If every path from y to the output meets g, then downstream output is determined by the one bit g when the remaining primaries are fixed. More formally, removing g separates x,y from the output; supply g externally, and every remaining output ancestor outside g is independent of x,y. Consequently the sets of possible g values at y=0 and y=1 as x varies must be disjoint nonempty subsets of {0,1}, hence different singletons. In particular h must take different values at the two y settings (otherwise both g sets agree). At each of the two possible values of h the truth table of g must be constant as x varies. Therefore g ignores x globally, contradicting x essential at its witness query. Phases do not affect this argument. In particular g is not the output vertex. This result applies to arbitrary reconvergence and free query-only signals. It does not assert every data path avoids g; it asserts at least one y path does.

## 2. Two distinct binary gates per deleted variable

Suppose x is essential at some query before deletion. Retain a nonempty query subset on which F is independent of x for every setting of all data; suppose at least one retained query depends on some other data y. Then delete x and keep the same target on the retained queries with all other data free.

If x has at least two distinct readers, set x to a constant. Every reader becomes a constant or a unary function, so at least two counted original gates disappear under signed alias simplification. This is true even if one reader was an ancestor of another; the input x itself is fixed for every reader.

If x has exactly one reader g, use the domination lemma to see that g is not the output. Every proper two-input truth table is either XOR/XNOR or canalizing in each of its inputs (the eight remaining proper functions are signed AND/OR). In the canalizing case set x to a suitable constant (accounting for phases) so g is constant regardless of h. In the parity case set x to h or its complement, with phase chosen so g is constant. The latter substitution can depend on all remaining data and query inputs; this is NOT a free computation being added to the circuit. It is valid because x appears only in g and every retained residual ignores x. Simply replace g by that constant, with no circuit added. Its live successor on some output path has a constant operand and becomes unary or constant; remove it too. Thus at least two distinct original data-dependent gates are eliminated. The transformed circuit computes the target on all retained queries and every remaining data assignment.

Stable ancestry charge: in the multiple-reader case both removed IDs are descendants of x in the current graph. In the sole-reader case the removed g and a direct successor are descendants of x. Alias rewiring only contracts existing directed paths; pruning and constant substitution cannot introduce new ancestry. Hence the two IDs have x ancestry in the original graph as well. Once eliminated they never reappear. Repeat the process for any valid deletion sequence, keeping all previous removals. This gives a simultaneous assignment of two distinct original gate IDs to each deleted variable, not a sum of independently computed lower bounds. Every charged gate lies in the original live cone. If a deleted variable is fixed by a function of other inputs, the only actual operation on the circuit is forcing its unique reader to a constant, so no substitution-induced new paths occur.

General target principle: if one can exhibit a nested sequence of query restrictions deleting p data variables under the above hypotheses, and a remaining core requiring at least b data-dependent binary gates, the original needs at least 2p+b. This is a structural B2 gate-elimination argument; it does not bound AND count when affine operations are free (the XOR reader and its successor can be XORs).

## 3. Core lemma: product with one two-entry table

Consider r>=1 independent groups. One group consists of two data bits a,b selectable by a query; each other group has one data bit z_j always selected. Thus the function is
    F=(selected a or b)*product_(j=1)^(r-1) z_j.
There are d=r+1 independent data bits. The allowed query set includes both selections and each data bit is essential somewhere. The function changes with the query for some fixed data. Even allowing arbitrary free query-only preprocessing, at least r+2=d+1 data-dependent binary gates are necessary.

Proof: suppose s<=d counted gates in the live graph. Cut away all query-only subcircuits, leaving their values as external query signals. Since every counted gate is live and the output is a counted gate, there are at least s-1 edges between counted gates (one outgoing for every non-output counted gate). The number of external input occurrences among the 2s operand slots is therefore at most s+1<=d+1. It is at least d+1: each independent essential data bit occurs at least once, and at least one query-only signal occurs because output genuinely varies with query. Equality must hold throughout. Every data bit and the single query occurrence is read exactly once, and every non-output counted gate has exactly one outgoing edge. The counted DAG is therefore a read-once tree with these external leaves. By Section 1, the sole reader of a cannot dominate another data bit: at the query selecting b, all other data except a are essential (each can be witnessed with the remaining selected bits set to 1); likewise for b. Thus the other operand of a's reader has no data ancestor in this tree and must be a query-only external signal. The same holds for b's distinct reader. This requires two query occurrences, contradiction. The proof also works for r=1: ordinary two-entry mux requires three counted binary gates. Upper core construction is three gates for the mux (two enabled terms and OR), then r-1 products; hence exact core data-dependent count r+2. No claim about cost of generating arbitrary query-only signals.

## 4. Independently addressed products and simultaneous subset allocation

Let r>=1 groups have sizes M_j>=2, total D=sum M_j independent data bits, and all independent address choices allowed. Target
    F(H,q)=AND_(j=1)^r H_j[q_j].
Every deletion from a group still having another entry can restrict to query addresses avoiding the deleted entry. The deleted bit was essential before (set other selected bits to 1), and some remaining selected bit is essential afterward. Thus Section 2 applies in any order as long as each group remains nonempty. Leave one chosen group with two entries and each other group with one. There are p=D-(r+1) deletions and the remaining core from Section 3 needs r+2 gates. Hence
    B_D(F) >= 2(D-r-1)+(r+2)=2D-r.
B_D counts original proper binary gates with syntactic ancestry in the table data, allowing free query-only preprocessing. For two equal tables D=2M,r=2 gives 4M-2. For one table r=1 gives 2M-1, attained with M data gates enabled by one-hot query signals and M-1 OR gates, so exact data-dependent B2 complexity when arbitrary query-only preprocessing is free. For general r an upper construction using one-hot gating and OR per table, then r-1 products, has 2D-1 counted gates; gap at most r-1 in this model. For actual total binary size, decoding one-hot query signals may cost extra gates. No claim of exact total B2 complexity or exact general batched data-dependent count.

**Stronger original-DAG subset constraints.** For any subset S of designated table data bits, let A(S) be the union of all original live binary gate IDs reachable from bits in S. Let f(S) count groups all of whose entries belong to S. Then
    |A(S)| >= 2|S|-f(S).
For S empty this is trivial. If f(S)=0, delete every bit in S in the original product target while keeping at least one address per group outside S. Section 2 supplies two distinct IDs per removed bit, each in A(S). No cost of the remaining core needs to be counted. If f(S)>=1, first fix every data bit outside S to 1. In a partially included group the query can bypass its remaining S bits by selecting an outside fixed-one entry; in a fully included group no such bypass is needed. Pick one full group with two surviving bits (possible since all original M_j>=2); leave each other full group with one. Delete every other S bit, including all optional bits of partially included groups, choosing bypass query values when a partial group becomes empty. Every removed bit is essential before its deletion by selecting it and setting the others to 1; after deletion at least one full-group bit remains essential. This is a valid query restriction, not an assumption of independence after arbitrary substitutions outside the retained query set. There are |S|-(f+1) deletions and a core with f+1 data bits requiring f+2 counted gates. All charged gates and remaining counted core gates have ancestry in S in the original DAG (restriction only contracts paths). Their disjoint total is 2|S|-f. This proves the inequality on the same physical gate ledger for every subset, even when S intersects many groups.

**Simultaneous Hall allocation.** Designate one arbitrary exempt bit per group, independently of the circuit. Demand one original gate for each exempt bit and two for every other table bit. In the bipartite incidence graph between demand tokens and original live binary gates, connect a token of x to each gate having x as ancestor. For any collection of tokens supported on S, the number of tokens is at most 2|S|-number of designated exempt bits in S, which is <=2|S|-f(S), since every fully included group includes its exempt bit. All these tokens together have neighborhood A(S), and the subset theorem gives Hall's condition. Thus a matching exists allocating every one of the 2D-r demands to distinct original gate IDs, each with the required ancestor. This is true for EVERY choice of one exempt bit per group (different matchings may be needed). No claim that the allocated paths themselves are vertex-disjoint or that the assigned gate outputs carry independent information simultaneously. This is a precise distinct-gate necessary topology certificate, checkable by bipartite maximum matching once a candidate DAG and its designated table positions are known. It can reject candidates with enough total gates but too few reachable from certain data subsets. It does not authorize adding matching demands from unrelated SAT restrictions.

For the shared-witness target with d=m*ell bits, choose one singleton row and one singleton column for each data bit. This restricts the allowed query set to individual retrieval of the d bits (address codes need not be binary counters). Same selector deletion proof yields B_D>=2d-1, and every proper data subset S has |A(S)|>=2|S| by deleting S leaving at least one other singleton query. Full subset bound gives Hall allocation with any one designated exempt bit. The stronger bound is on original B2 gates, not a doubling of the earlier d AND lower bound in the same model.

## 5. Transfer to actual packed SAT and scope

Use the previously verified batched packed lookup grammar, where all table bits occur once at independent fixed physical positions, independent query addresses are encoded by free polarity bits, and other physical input bits are fixed constants. For group count r and table size M=2^k in that construction, D=rM; at its valid lengths we now obtain at least 2rM-r original binary gates with designated table ancestry. For two groups: 4M-2. For shared witness the earlier active/parking pattern grammar has d=m*ell independent single-copy data bits and query row/column masks. Its singleton contexts are valid; bound 2m*ell-1 and subset matching apply at those valid lengths.

In both cases a fixed restriction and simplification of an arbitrary original SAT B2 circuit preserves original gate IDs for all retained binary gates and cannot create new ancestry. The bounds and matching therefore hold also in the original SAT DAG with respect to those designated physical data positions. Query-only preprocessing in the restricted circuit is free here; that relaxation only weakens the necessary bound. No new grammar, padding proof, or physical-coordinate replay this round. Do not identify designated positions across different encodings without a separate mapping proof. These are improved B2 allocation bounds for particular existing restrictions, NOT necessarily improvements over the repo's existing strongest total SAT circuit lower bound at the same length. The targets have linear or quasilinear upper constructions and these new lower bounds remain linear. No originality claim: classical gate elimination and selector circuit complexity have substantial prior literature, not reviewed here for priority.

## 7. Next direction

This round leaves aggregate rank and supplies a classical-style structural elimination rule, with a simultaneous original-ID matching certificate. Independent audit/Lean formalization still outstanding. Engineering may implement the Hall check after audit; it is a necessary condition on a specified topology with valid target witnesses, not sufficient for correctness. Seek harder packed targets with query avoidance/elimination sequences that force MORE than two original gates per step, or cascade multiplicities that produce a superlinear average without charging a gate twice. Two-gate per data deletion and its Hall allocation have an intrinsic linear ceiling; they are not a solution to L-clb-036. The useful next question is whether cascades or incompatibility of matchings across genuinely different legal restrictions can force many more distinct gate IDs in the full SAT DAG, rather than proving further tight constants on easy lookup targets. No production changes, new physical grammar, external submission or superlinear claim.
