## 1. Exact reduction, including unknown anchors

Use GF(2). For a fixed proper input split, reshape a partial truth table into an m-by-n matrix A, entries 0,1,? (unknown). Every completion is an independent choice of bits for unknown cells, subject only to the original care mask. For a complete matrix C, its anchored mixed rank is rank of H_ij=C_ij+C_i0+C_0j+C_00, precisely the native header's anchored_rank. Write R_min(A)=min over all completions of this rank. Any circuit consistent with the care mask computes some completion, so its structural mixed AND count is at least floor(log2(R_min+1)) by the prior scalar theorem. No assumption that unknowns are zero. This is the same floor as bit_width(R_min+1)-1, not floor(log2 R_min)-1.

Let pi:GF(2)^m -> GF(2)^(m-1) send v to (v_i+v_0) for i=1..m-1. Kernel is the span of the all-ones vector. For each column j let S_j be the image under pi of all column vectors agreeing with its specified entries. S_j is a nonempty affine subspace; if there are no specified entries it is the whole quotient. If a column has at least one known row k, write a quotient vector as w with w_0=0. It is in S_j exactly when
    w_i+w_k=A_ij+A_kj
for every known row i of that column. This follows by solving the common unknown lift constant v_0=A_kj+w_k. In particular neither the first row nor the first column need be known.

For a complete C, put w_j=pi(C_column_j). The nontrivial columns of its anchored matrix are exactly w_j+w_0, where here w_0 denotes the projected FIRST COLUMN (not the zero coordinate within a quotient vector). Thus rank equals dim affine hull{w_j}. Conversely every independent choice w_j in S_j lifts to a completion column by column. Therefore
    R_min(A) = min { dim L : L affine flat in GF(2)^(m-1), L intersects S_j for every j }.
Proof both directions: a completion supplies the affine hull of its projected columns, intersecting all S_j; a hitting flat supplies a choice of point in each S_j, and the resulting completion has rank at most its dimension. Equality follows by minimization. Transposing A preserves the minimum rank, so choose the smaller matrix dimension for m. This is a purely algebraic result and does not rely on the sharp joint theorem.

Decision R_min<=k is exactly existence of a hitting flat of dimension k, for 0<=k<=m-1: any smaller flat extends to a k-flat. A complete hitting flat with representative and basis plus one chosen point in each S_j is an upper certificate on minimum rank (not a gate floor). Exhausting all candidate flats with no hit is a lower certificate. A timed-out search or failure to find a flat heuristically is NOT a lower certificate.

## 2. Algorithms and resource budget

**Rank zero.** Build a bipartite graph with one vertex per row and column and one edge of label A_ij per known entry. R_min=0 iff row and column potentials u_i,v_j exist with u_i+v_j=A_ij for all known edges. Indeed a rank-zero completion is precisely an additive row/column matrix (expand the anchored identity); any consistent potentials define such a completion. Equivalently the XOR of labels along every graph cycle is zero. A DFS/BFS assigns potentials in O(m+n+known entries), or parity union-find gives a near-linear incremental algorithm. Inconsistent cycle gives a checkable certificate using only known entries. No cycle means no obstruction; it does not establish a circuit with zero mixed gates for a different care constraint.

Example (rows separated by semicolon):
    [0,?,1; 0,0,?; ?,0,0].
Known entries form a six-cycle with odd label sum, so minimum rank>=1. Filling the question marks with zero has rank1, proving equality. Every fully specified rectangle has at most one row or one column and mixed rank0. The 3x3 matrix itself is an illustrative matrix, not a full Boolean split; it embeds into a 4x4 split by leaving the extra row and column all unknown, preserving minimum rank.

**Fully specified rectangles.** Every all-known rectangle gives a lower bound on R_min via its anchored rank, anchored at ANY row and column within it. Restricting a complete matrix to that rectangle amounts to row/column restrictions of its additive-quotient mixed factors, so cannot increase rank (equivalently each local anchor difference is a sum of original anchor differences). Can enumerate all subsets of rows for small m and include all columns known on those rows; this finds maximum known-rectangle rank since adding fully specified columns cannot lower rank. Odd-cycle test can strictly beat this method.

**Exact flat enumeration for small m.** Enumerate linear k-subspaces in RREF over GF(2)^(m-1). For each, enumerate affine cosets through a point of the smallest S_j; deduplicate by coset representative. Accept if the coset intersects every S_j. Membership/intersection can be implemented as bitsets (m<=8 -> 128-bit masks), or via the rank of linear equations on flat coordinates. No need to enumerate all 2^holes completions. Number of all affine k-flats in an ambient h=m-1 cube is 2^(h-k) times Gaussian binomial [h choose k]_2. For h=7, k=2 this is 32*2667=85344; k=6 is 2*127=254. For h=3,k=2 it is 2*7=14. The chosen smallest S_j filter can reduce candidates substantially; no runtime guarantee beyond finite enumeration. For m=16 and larger, exhaustive dimension-2 enumeration is already enormous, so enforce size/time/candidate caps or use SAT formulation. The reference JS implements small matrices only, using 32-bit shifts; do not reuse it for arbitrarily large dimensions.

**Only decide thresholds the solver needs.** A floor of at least 1 requires R_min>=1 (exclude rank0), floor>=2 requires R_min>=3 (exclude rank<=2), floor>=3 requires R_min>=7 (exclude rank<=6), etc. There is no need to find exact minimum for every split. If threshold infeasibility is fully checked, emit its sound floor; otherwise fall back to independently certified weaker bounds. For n_inputs<=6 on balanced Boolean splits m<=8, so threshold-2 enumeration is bounded by 85344 flats per split before smallest-set filtering. This does not imply worthwhile runtime in Percy; benchmark preprocessing and solving together. Rank-zero cycle checking is much cheaper and likely the right first integration, though the complete-function benchmark suggests even floor1 may not pay off.

Alternative SAT formulation for threshold k: unknown row offsets u_i, column offsets v_j, row factors p_i in GF(2)^k, column factors q_j in GF(2)^k; impose u_i+v_j+p_i dot q_j=A_ij for each known entry. Satisfiability iff R_min<=k, because additive row/column terms disappear under anchoring and anchored rank-k factorization reconstructs a completion by adding back row/column offsets. UNSAT with independently trusted certificate supplies floor; SAT supplies no floor above k. This is an alternative exact formulation, not a new implemented solver.

## 4. Other three engineering bottlenecks and corrections

1. A universally linear-in-R lower bound on mixed AND count is impossible. The sharp rank-one chain attains R=2^(t+1)-2 with t ANDs in the free-affine XOR-AND model. Even in AIG, simulate each XOR by a constant number of ANDs; the same family has O(t) AIG gates (and hence O(t) mixed gates) while R exponential. Additional structural hypotheses are required, e.g. restricted dependency graph or pinned local cuts. Do not allocate research to proving an unrestricted linear floor that the tight examples refute.

2. The general joint ceiling already has a paper proof in chatgpt_handoff/joint_augmentation_rank_handoff.md (641f35b), reconciled in translation_rank_reconciliation_audit.md (9bac608). Independent audit outstanding; do not enable unverified joint pruning by default. More importantly the joint theorem combines multiple outputs under ONE COMMON data/query split and one common mixed-gate ledger. It does not automatically sum floors from distinct input partitions, even for a single output. Percy single-output global cut floors remain separate simultaneous inequalities; overlapping counts cannot be added without a separate valid theorem.

3. Partial table implementation notes: keep the current --dc rejection until a verified care-aware path exists. Complete-table cut_floors currently computes essential_inputs and swap_symmetric from a complete vector f. For partial tables only a known opposite-valued pair differing in one variable certifies essentiality for EVERY completion; absence of such pair does not certify inessentiality for every completion. Safest initial partial mode enumerates cuts of all original inputs (one per complementary pair), with no essential-input dropping. In particular do not remove variables merely because a filled-in completion looks inessential. For symmetry cache, a permutation must preserve the care mask AND the specified values on its support; symmetry of arbitrary filled bits alone is not enough. Pairwise such swaps generate class permutations preserving the set of completions. Disable caching initially if in doubt. Use the exact bit_width threshold from existing code, not a changed floor. The above proof is for complete single-output functions consistent with independently unknown entries; additional completion constraints could only raise minimum rank, but do not use a completion solver assuming them unless certified.

4. Local floors: a fixed internal wire whose function is certified (including under a valid partial constraint) can be assigned its own mixed-rank floor on its actual ancestor cone. Several such local constraints may coexist; their counts cannot be summed when cones overlap. For a fixed cut, if known cone membership gives c already pinned mixed gates, only max(0,floor-c) additional mixed gates in the unpinned part of that cone are required. This is elementary safe subtraction, not a floor on the residual output after arbitrary prefix elimination. Generic engines that do not expose internal functions or a pinned cone cannot use this without extra infrastructure. A more promising low-overhead research result for the selector restrictions is the phase-independent optimistic restriction quotient and Hall matching in restriction_stable_ancestry_handoff.md (536d02a). It requires certified independently retrievable data contexts; it is not a general test for every 4-input target and has not been benchmarked in Percy.
