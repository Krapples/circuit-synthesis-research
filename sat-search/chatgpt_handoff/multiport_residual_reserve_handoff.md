# Metadata-dependent multiport residual and branch reserves

Date: 2026-11-26. Continues pair_cofactor_branch_handoff.md (5bbd4cd) and the previous programmable dictionary / switchable incidence construction. Paper theorem, small finite regression, no independent audit, Lean proof, production changes or unrestricted superlinear SAT lower bound. L-clb-036 remains open.

## 1. Frontier model

Take a live signed AIG with proper distinct operands, free signs and constants. Designate d essential independent data primaries S, and treat all other primaries as query inputs on a common domain independent of the data cube. Select a topological prefix containing S (query primaries may be regarded as initially available). Let K be the distinct data-dependent vertices in the prefix that are read outside it, including the output if in the prefix. Let c=|K|, counting raw data primaries as well as gates. Retain the union of the data-dependent ancestor cones of K within the prefix; all data primaries belong because they are essential and all their paths to the output meet K. Let B count retained gates. Let q be the number of distinct underlying data-free signals feeding these gates, Q their total operand occurrences. Data-free means no syntactic S ancestry, so each is a function only of the query. The prefix is important: there is no feedback from its complement into its gates. All data-dependent inputs to the suffix pass through K; query-only signals bypassing K may be arbitrarily numerous.

For each fixed query, the map S -> values(K) is determined entirely by the q ingress bits. At most 2^q maps occur. For a fixed map H:{0,1}^d->{0,1}^c, the final residual is h_y composed with H, for some arbitrary Boolean function h_y on c bits. Therefore at most 2^(2^c) residuals occur per map. If R distinct output residuals occur, R<=2^(q+2^c), hence q>=max(0,ceil(log2 R)-2^c). This is a counting upper bound on maps, not an assertion that all maps or suffix truth tables are attainable. More precisely if a map has image size r, it admits at most 2^r functions, including both constants. Consequently R<=2+2^q*(2^(min(2^c,2^d))-2). The latter is useful for c=1: at most two nonconstant residuals per map, so q>=ceil(log2((R-2)/2)) for R>2. Use the simpler bound in the main ledger.

## 2. Local branching separation

In the retained prefix data-dependent graph stop each input's unique-successor walk at the first vertex of distinct outdegree >=2 OR at a port in K, whichever comes first. Each data primary reaches at least one port. If two inputs have the same endpoint, their paths meet at a gate before either can leave via a port or branch (the meeting gate can be the endpoint itself). All paths from these inputs to the frontier pass through that meeting gate. With other primaries fixed, each side operand on the arms is constant: it cannot have ancestry from either of the pair without contradicting the unique paths and first meeting. Whenever both inputs remain essential in the final output cofactor, every arm AND must pass its signed input, and the meeting computes the same signed AND of the pair regardless of context. All frontier values, and hence final output, are functions only of that one bit with other primaries fixed. Any essential cofactor must be the signed AND or its complement. Thus the endpoints properly color the incompatibility graph G of pairs admitting two essential cofactors that are neither equal nor complements, exactly as in pair_cofactor_branch_handoff.md. This argument handles metadata-dependent frontier maps; it does not assume the suffix function stays fixed between cofactors.

Let I be raw data operand occurrences and E internal retained gate operand occurrences. Partition ports into c_p primaries and c_g gates. Every nonport data primary has at least one outgoing retained occurrence, and every nonport retained gate also has at least one. Define e=I-(d-c_p)+E-(B-c_g)>=0. Exact operand-slot count yields B=d-c+Q+e. Each distinct branch endpoint outside K contributes at least one to e, as its outdegree exceeds its baseline one; endpoints in K need not be charged. Therefore e>=max(0,chi(G)-c). Combining with Q>=q yields
    B >= d-c+max(0,chi(G)-c)+max(0,ceil(log2 R)-2^c).
For pair-complete data S, c<=d, this simplifies to
    B >= 2(d-c)+max(0,ceil(log2 R)-2^c).
One can use the improved nonconstant-residual count from section 1 instead. No claim for B2 parity primitives at the same cost: unique XOR arms can change polarity with the query. No assumption that all branches are used simultaneously on any one input. Charges concern distinct operand occurrences in a single exact ledger, not a sum of gate-cone lower bounds.

## 3. Dictionary slot application

In the already proved switchable incidence layout, retain d bits of ONE payload slot, fix all other payloads to zero and use the dictionary mode with only this slot active. By programming h arbitrarily on the retained coordinates, the residual family contains all 2^(2^d) Boolean functions of those bits. Every pair has both AND and OR cofactors (choose dictionary entries and fix the other data coordinates). The same physical data coordinates are free in all contexts. Therefore for every topological frontier with c<=d,
    q >= 2^d-2^c,
    B >= 2(d-c)+2^d-2^c.
If c=d-1, at least 2^(d-1) distinct query-only wires must have entered the retained data-dependent prefix, and B>=2^(d-1)+2. If c=1, B>=2d+2^d-4 (the refined residual count improves ingress by one for d>=2). With no metadata ingress, the counting theorem forces c>=d; this recovers the ordinary injective encoding bound for a universal dictionary. More generally the formula for pair-complete S spanning slots can use the graph residual lower bound in programmable_tag_residual_handoff.md. These are constraints on the same original gate IDs after constant restrictions and simplification; do not add separate frontier inequalities along a path. The cones are nested/overlapping, not disjoint.

Explicit limitation/positive control: compute a dictionary lookup by a binary mux tree taking 2^d independent query-only table bits and d data address bits, then use its output as the frontier (c=1). It realizes all 2^(2^d) residuals with q=2^d and 3(2^d-1) ordinary signed AND gates, all data-dependent. Thus exponential ingress in d is feasible, not contradictory, and for physical dictionary packing the query table itself has exponential-in-d length. More importantly, a large circuit can select one slot and reuse a single dictionary evaluator across many different slot restrictions. This theorem does not prevent that sharing, and summing slot-local charges would double count. Since log R cannot exceed the number of independently varying query bits, this residual counting route alone is capped at linear physical input scale.

## 5. Next step

A successful multistage gate bound needs a genuinely disjoint charge or a restriction-stable potential with telescoping increments; merely summing these prefix reserves is invalid. The local theorem supplies a new condition on WHERE metadata enters before compression, but a shared encoder may still satisfy all individual cuts. Seek an analogue for separate data blocks with conflicting query-dependent compressions and prove an additive resource inequality on disjoint regions, or prove a barrier via a shared decoder control. No superlinear bound, independent audit, Lean check or native modifications.
