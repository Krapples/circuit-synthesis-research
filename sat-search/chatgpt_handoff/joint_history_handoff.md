# Joint response histories, specialized-copy flow, and affine correlation obstruction

Date: 2026-11-26. Base [5829985](https://github.com/Krapples/circuit-synthesis-research/commit/58299857e0cc1f0542a6a03547240f1a2db426f9). Extends [feedback_compatibility_handoff.md](feedback_compatibility_handoff.md) and [causal_response_handoff.md](causal_response_handoff.md). New joint code and history-expanded flow invariants retain correlations between multiple forward signals, with an original-gate charge using copy multiplicities. Explicit signed AIG families pass ALL old internal cuts even using exact individual response capacities, yet fail the new joint capacity by an unbounded factor. No unrestricted superlinear numerical size lower bound, Lean theorem, production solver modification or literature-priority claim. L-clb-036 remains open.

## 1. Model and joint codes

Retain the original circuit DAG partition A,B, output in B, free data S in A, all other A primaries fixed publicly. Bob's common allowed input domain Y is independent of the data assignment x. Forward ports F and reverse ports R are distinct original vertices. For each v in A let R(v) be the reverse vertices reaching v through a B-to-A wire followed by an A-only path. Break all B-to-A edges and supply a formal global reverse history h in {0,1}^R. The resulting local computation at v is T_v(x,h), independent of the components of h outside R(v). This definition is valid even if actual feedback is data-dependent.

Let H be any fixed common overapproximation of all actual complete reverse histories across x and y. In particular choose all formal histories, which needs no semantic knowledge, or certify a smaller common set using the previous feedback separator theorem. For a set K of A vertices, define a joint response code

    J_K(x) = ( (T_v(x,h))_(v in K) )_(h in H).

For any A-only vertex cut K meeting all S-to-F paths, the number N of distinct output residuals on Y satisfies

    log2 N <= log2 |image J_K|.

Proof: the code gives a complete decoder at each cut vertex for every local reverse history that can actually occur. When v is evaluated in the original topological order, its earlier reverse ancestors have already been correctly reconstructed, by the previous causal-cut argument. Choose any h in the COMMON H extending the currently observed R(v) coordinates. Such an extension exists for the original x,y, and every extension has the same T_v(x,h) since the other reverse coordinates do not affect v. Read that component of the joint table. Crucially, one does not wait for the later reverse coordinates or require the chosen extension itself to be realizable at that x. Proceed with the earlier cut reconstruction proof. Equal joint codes imply equal output residuals. For H the full formal cube the extension can simply set every unobserved bit to zero.

One semantic refinement is to form the union of the previous per-vertex partial-response conflict graphs on X, over v in K. Proper coloring of this UNION graph is exactly the minimum number of joint messages permitting separate history-only decoders at every cut vertex. Each color is an independent set in every G_v, so their partial functions merge consistently at each vertex. Conversely any such shared message partitions X into sets independent in every G_v. Thus

    log2 N <= log2 chi(union_(v in K) G_v)
            <= sum_(v in K) log2 chi(G_v).

Also chi(union G_v)<=|image J_K|: equal joint tables give compatible partial functions. This is a paper observation, not a new joint-coloring experiment. It gives a semantic compression target; exact chromatic number or exact joint image can depend on the unknown circuit semantics. The next sections supply noncircular certificates computed from specified signed AIG wiring and phases, without enumerating all data assignments. They are not topology-only for arbitrary choices of gate functions.

## 2. Specialization into stable original gate copies

For each h in H instantiate the local A DAG, fixing the broken reverse ports to h and public A constants as prescribed. Each remaining source is a member of S. Simplify by exact identities: constant folding, signed aliases, identical or opposite operands, commutative structural hashing. The representative of each retained AND is an ORIGINAL A gate ID, not a newly synthesized gate. Alias to an earlier signed primary/gate or a constant is allowed; prune dead nodes with respect to the desired joint outputs K. Complemented edges are free throughout.

One can additionally certify semantic aliases without using exhaustive truth tables. The reference uses an affine pass over GF(2): label each free primary with its affine basis vector, each constant with its scalar, and propagate labels through constants, signed aliases, equal/opposite inputs. Recognize an XOR/XNOR macro when an AND reads the complements of two A-side AND gates whose signed operand pairs are exact complements of one another up to swap. For signed inputs p,q,

    NOT(p AND q) AND NOT((NOT p) AND (NOT q)) = p XOR q.

Both children must be on A (a broken B input is an independent formal parameter, not its original circuit formula). Thus if p,q have certified affine forms, the macro output has their sum; complemented output phases adjust the constant term. This local identity proves the label inductively. Hash equal affine forms and opposite phases to earlier existing original representatives. For nonrecognized nonlinear gates keep the ordinary original AND; never assume an unknown label is affine. The pass can simplify signed AIGs with XOR structure without requiring arbitrary equivalence testing. It is not a topology-only certificate if phases are not specified, and is not a complete affine recognizer. In a synthesis search with unknown phases a phase-independent argument or branch-specific certification is necessary.

A copy for h is now an acyclic graph C_h whose vertices are identified by stable original IDs, with signed input/output aliases. Every original A vertex value at history h is preserved under those aliases. Let K_h denote the nonconstant representative vertices for K. Signed aliases to the same vertex count once; constants have no vertex demand. Denote its live gates by L_h. These simplifications preserve response semantics for every data x, not only actual reachable histories. Fixed public A constants can be substituted initially. The checker specializes all formal histories with all A primaries free.

## 3. History-expanded flow theorem (joint and source-shared)

Construct one disjoint copy of each C_h, with each vertex (including a primary occurrence in a copy) of unit capacity. The copies share only the following virtual interface: one vertex per original free data source i in S, of capacity one, feeding its corresponding primary occurrence in every copy. Add a supersource feeding these shared data vertices, and a supersink fed by all representative vertices K_h in all copies. All other edges may be assigned capacity |S|+1 (effectively infinite). Let L(K) be the integral maximum flow value from supersource to supersink.

**Theorem.** If K intercepts all local data-to-forward paths in the original DAG,

    log2 N <= log2 |image J_K| <= L(K) <= |S|.

Proof of the second inequality: any finite network cut of capacity <=|S| cuts only unit vertex-capacity edges in the usual vertex-split construction. It therefore consists of shared source vertices and individual copy vertices, with one bit per cut vertex. Encode the actual values at those cut vertices under a given data assignment and the corresponding fixed h. They determine all the joint response outputs in all copies: evaluate recursively from each K_h, stopping at a cut vertex or a public constant; a path to an unencoded varying data bit would contradict separation from the supersource. All copy representatives are known functions of x, so the number of codes is at most 2^(cut size). The first inequality follows from Section 1, and the min-cut theorem gives the second. Cutting the shared sources costs |S|, proving the last inequality. No independence of responses or actual histories is needed. The cut can choose different original gate IDs in different copies, and may cut shared sources only once. This is stronger than merely adding independent per-history cut capacities, since it includes shared data-source consistency. It is not in general a monotone improvement of the previous exact per-vertex flow for every graph: the older flow can exploit compression across histories missed by copy-wise cuts. Take the minimum of certified capacity upper bounds when rejecting topology/phase assignments.

In particular one may use the cheaper upper bound

    L(K) <= sum_(h in H) min_vertex_cut(C_h, S, K_h),

with unit capacities and endpoints allowed. The right side is the min-cut value of independently sourced copies, equivalently a network with nonbinding shared-source capacities. Each per-history cut can exploit common response signals at that history. Different histories need not have the same cut. The shared-source flow can additionally reduce this sum by preventing multiple copies from counting the same original primary's independent information more than once. For cut K=F no earlier internal cut choice is required; min-flow over all copy cuts is computed directly.

### Distinct original-gate charge

In the injective case N=2^|S|, the lifted max flow is exactly |S| and gives one unit path from every shared data source, by integrality and the shared source capacity. Each such path enters exactly one history copy. Let m_v be the number of histories for which original A gate v survives in the live cone of F_h in C_h, i.e. the number of live copies of v. At each live copy of v charge a path 1/m_v (no charge for original or copied primary vertices). Let d_i^lift be the minimum cost among all source-to-sink paths beginning at data source i in this lifted graph, ignoring other paths' capacities. Then

    sum_(i in S) d_i^lift <= # {v original A gate : m_v>0} <= s_A.

Proof: at most one unit path traverses each live copy, so summing 1/m_v over all the copies of v gives at most one. The actual integral flow supplies paths of total cost at most the number of original live gates. Shortest-path costs cannot be larger than those supplied costs. No claim that these paths are physical simultaneous signals or prescribed partner routes. A stronger variant: for each v distribute a nonnegative charge budget lambda_(v,h) over its live copies with sum_h lambda_(v,h)<=1. The same proof works with these costs instead of uniform 1/m_v. Thus one can optimize this certified bound over charge budgets (a finite LP using path constraints/shortest-path separation); no such optimization is implemented here. The uniform metric and the old inverse-capacity metric are separate lower bounds; they cannot automatically be added or assumed to dominate each other. This lifted charge is valid even if aliases remove gates in some histories but not others, because representatives use only stable original IDs. Replacing copies with an arbitrary smaller resynthesized circuit would need additional accounting and is not authorized by this proof.

## 4. Strict separation even from exact individual response capacities

Let M=2^k>=2, r>=2 a power of two. Use r data tables H_i, each M free bits, in A. Bob holds a common k-bit query q and a log2 r-bit port-selection query j. Put the usual signed mux tree computing p_i=H_i[q] in A for each table. Compute the signal e=[q!=0] in A and define r A-side forward outputs

    f_i = p_i XOR ( e AND XOR_(l!=i) p_l ).

The B region multiplexes the f_i using j; no other A-to-B ports are needed. This is a concrete signed AIG with O(rM+r^2) gates (use separate XOR sums), and r=M gives linear size in the rM data bits. It is NOT a circuit computing the target two-address INDEX function H_j[q]. Rather it is a candidate gate/phase assignment whose responses will be shown insufficient for that target. Every data bit is individually essential in its actual output: q=0,j=i reads H_i[0], and q!=0 reads the parity of all H_l[q], which changes when any one changes. So lack of individual essentiality is not the reason for rejection.

At q=0, all f_i=p_i, independently. At every other q, all f_i equal the SAME parity XOR_l H_l[q]. Therefore the joint response vector across all histories is an affine (in fact linear) map of exact GF(2) rank

    r + M - 1,

because it records r independent bits at q=0 and one independent parity at each nonzero address. Distinct output residuals on (q,j) number exactly 2^(r+M-1), not 2^(rM). For the intended target INDEX all rM bits have distinct joint residuals, so these fixed signed AIG responses cannot suffice. In particular the sum of exact per-port response log cardinalities equals rM, overestimating the joint capacity by a factor rM/(r+M-1). Choosing r=M makes this factor Theta(M), unbounded. The same example can be interpreted as a failed candidate implementation for the earlier enabled lookup promise with one selected group, on a legal Bob query domain in which exactly one lookup is active and all groups receive the common address. That is a restriction of the permitted communication input domain, not a new packed word projection or a new physical-coordinate assertion.

**Every old causal cut passes, even with exact individual capacities.** For each data table i fix all other tables to zero, and vary H_i arbitrarily. Along the ordinary mux-tree data paths leading to p_i, each AND branch or completed mux contains the full independent responses on precisely its selected leaves, since q is independent of all data and ranges over all addresses. Thus its exact individual response log-cardinality is at least the number of data sources routed through that branch or merge. At p_i it is M. In the final XOR implementing f_i=p_i XOR b_i, b_i=e AND XOR_(l!=i) p_l=0 on the chosen subfamily. Its AND branch p_i AND NOT b_i therefore carries the full p_i response, and so does the output (up to sign). Send one virtual unit from each of the M sources of table i along their mux paths, then this direct branch and final XOR gate to f_i. The paths for different i use disjoint A gate sets (other-table parity logic is off the chosen paths). The actual exact individual capacities are at least the loads, as certified by those separate subfamilies. Because q values are reachable for every x and independent of x, the previous partial-response coloring equals the number of distinct local total tables for these vertices; no hidden data-dependent reachability assumption. This gives a full rM-unit flow under even those exact individual capacities. Hence all previous individual-capacity internal-cut inequalities pass the rM demand. These older inequalities genuinely fail to detect the missing joint information; they are not merely a poor choice of original cut.

**New joint cut rejects.** After specializing q=0 the forward representatives are the r original data bits H_i[0]. For q!=0 the forward outputs are all the same affine form, and the signed affine hash described above identifies them with a single earlier existing representative. Thus one cut vertex suffices for the nonzero history, and r vertices suffice for history zero. The independent-copy cut gives r+M-1; the source-shared lifted min-cut is exactly this number by the joint response rank lower bound on any code. This shows a strict separation for the specified AIG wiring AND PHASES. It does not show that every assignment of other binary functions to that underlying graph is rejected; in particular the final mixing gates could be repurposed in a different circuit. The original feedback separator theorem was topology-only, while this new simplification uses gate semantics that are locally known in a candidate signed AIG. That distinction is essential when discussing unrestricted lower bounds.

With M=r, all previous exact individual cut capacities support M^2 source units, and the new joint lifted capacity is only 2M-1. This is a polynomial-factor separation in the data length, in a linear-size candidate graph. It is not a lower bound exceeding linear size for the target function. Correct independent table muxes followed by the B selection have O(rM) gates and pass the joint tests; likewise the previous programmable enabled packed lookup sorting control remains quasi-linear. All actual valid circuits necessarily pass the general inequalities.

## 5. Executed finite regression

Run from this directory:

    node joint_history_check.js

Actual full-circuit feedback may depend on the data. 1,187 original internal cut tests, 36,072 direct full-output reconstructions from joint code with dummy A data and arbitrary extension of each earlier local history. 270 strict exact joint-image reductions relative to the sum of exact local formal response log cardinalities; 913 cases where the shared-source lifted flow is lower than independent-copy flow; 67 injective full-flow weighted gate-charge checks. In this random/mux sample there were no strict reductions of the lifted forward min-cut relative to exact individual formal response flow, and no extra strict affine-flow reductions relative to ordinary hash simplification. These zero counts are explicitly reported, not suppressed. The improvements below are targeted separating families. Small exact formal histories are not the same as exact actual-history color counts in a general random circuit with feedback; no such equivalence is asserted outside the independent-query family.

Nine explicit correlated-response AIGs with k=1,2,3 and r=2,4,8. Lower capacities certified by varying one entire table at a time while all others are zero, enough for the old flow to saturate all rM sources. The checker computes the exact joint affine rank from symbolic GF(2) forms and separately computes the stable-ID affine lifted min-cut, matching r+M-1 in every case. Basic constant/hash specialization already catches r=2, but fails for the six cases r=4,8; the affine pass fixes that limitation. For largest tested k=3,r=8, 64 data bits and 367 AND gates, old exact individual capacity flow=64, ordinary lifted flow=64, affine lifted flow=15, joint affine rank=15. 720 independent sampled full-circuit assignment comparisons with the formula in Section 4. General separation proof is algebraic, not extrapolation of finite tests. All final assertions passed. [Replay](joint_history_replay.txt).

The first checker used plain structural hashing, which missed correlations between different XOR expressions in larger families. Added the sound local affine recognition and alias pass; also increased the effectively infinite capacities for the independent-copy comparison to exceed |S| times the number of copies, so its flow correctly models the sum of independent-copy cut capacities. No exact joint conflict coloring, optimized charge-budget LP, new SAT grammar or padding/slice replay, native full SAT AIG synthesis, or Lean verification this round. No production solver changes.

## 6. Research interpretation and next tasks

We now have a hierarchy of useful tests, not a solved asymptotic bound. The original causal flow counted each gate's possible responses independently. The previous feedback separator improved individual history cardinality. The present lifted cut preserves joint response correlations across different gates at each common history, and preserves source identity across histories. The affine example proves that even EXACT individual response capacity is insufficient: a circuit may locally carry each table fully while losing distinctions in the final joint table.

Next: (1) independently audit the common-history extension argument with later feedback, stable-ID specialization, affine macro recognition, shared-source flow and per-original-gate charging; replay all examples; (2) explore small symbolic history covers or block partition refinements that avoid enumerating 2^|R| copies; (3) investigate necessary joint rank or entropy of response vectors under SAT restrictions with independently programmable shared existential constraints, not only muxes; (4) optimize charge budgets or seek a combined bound on the cost of creating distinct history-dependent live gates and preserving their joint independent data. A proof of unavoidable superlinear total cost remains missing. Do not add overlapping cut/metric charges without a new capacity proof, treat aliases in different contexts as distinct original gates, or mistake a necessary topology/phase test for a bound on arbitrary unknown circuit size. Correct sorting/mux, two-read and previous Andreev/Tseitin/cubic controls remain essential. L-clb-036 remains open.
