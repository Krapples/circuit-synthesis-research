## 1. Exact period invariant

Fix a legal causal partition and an original internal cut K (or forward ports F), with data x in GF(2)^d, output on Bob's side and common allowed Bob domain independent of x. Let J(x) collect all response bits of K over a COMMON formal history set covering actual histories. The earlier reconstruction theorem gives log2 N <= log2 |image J| for the residual count N. The history set may be the full formal cube; do not use a different arbitrary domain for each x.

For any Boolean vector map J, define
    P(J) = {a in GF(2)^d : J(x+a)=J(x) for every x}.
It is a linear subspace: zero is a period and the sum of two periods is a period by composing translations. J is constant on its cosets, so
    log2 N <= log2 |image J| <= d-dim P(J).
Moreover d-dim P(J) is EXACTLY the minimum rank of a linear encoder L for which J(x)=g(Lx) with arbitrary decoder g. Necessity: ker L subset P(J). Sufficiency: choose a quotient linear map with kernel P(J), and define g on each coset. The decoder need not be efficient. For affine J this recovers exactly the coefficient matrix rank (drop constant columns). For nonlinear J it is not the entropy or general minimal code length: e.g. OR on d>1 bits has only two outputs but trivial period space. Never use period CODIMENSION as a lower bound on residual count or on maxflow. It is an upper bound used for rejecting a specified candidate. This is a standard translation-invariance/linear-factorization notion; no originality claim for the general algebraic concept.

The certificate can also cover part of a joint table: if J=(J_0,J_1), use a linear quotient for J_0 and send one bit per component of J_1, so log2 N <= codim P(J_0)+number of J_1 components. A linear quotient on the whole data space need not be appropriate after restricting to nonlinear data promises; this proof is for full binary data cubes (or affine subspaces parameterized by independent coordinates).

## 2. Exact degree-descending algorithm

Assume exact algebraic normal forms (ANFs, square-free Boolean polynomials) for all selected response functions are given. Let D be the maximum degree. For a direction a, let Delta_a J(x)=J(x+a)+J(x). Translation cannot increase degree, and degree-D terms cancel in Delta, so deg Delta_a J <= D-1 for every a. Degree is the maximum across outputs; the zero vector polynomial has degree -infinity.

Define V_k={a : deg Delta_a J <= k}. Initially V_(D-1)=GF(2)^d. The cocycle
    Delta_(a+b) J(x)=Delta_a J(x+b)+Delta_b J(x)
implies, inductively, that on the subspace V_k the map a -> homogeneous degree-k coefficient vector of Delta_a J is LINEAR. Indeed translation of a polynomial of degree <=k preserves its degree-k homogeneous coefficients. Thus V_(k-1) is exactly the kernel of this linear map restricted to V_k. Iterate k=D-1,...,0. The last kernel V_(-1) is exactly P(J). For constant J, return the whole space immediately.

At each stage evaluate the derivative signatures only on a basis of V_k, and perform GF(2) elimination tracking the corresponding input directions. For monomial x_A=product_(i in A)x_i, translation adds the expansion terms x_(A\B) for every nonempty B subset of A intersect supp(a). Cancel repeated terms over GF(2). This computes the exact ANF derivative; no numeric rank, no sampled equality and no exponential enumeration of data assignments needed. Each derivative expands at most 2^D terms per original monomial. There are <=dD basis derivative evaluations, and elimination is polynomial in the expanded explicit coefficient universe. Thus for fixed D this is polynomial in the given sparse ANF input and d. If the circuit has huge-degree/dense ANFs, obtaining these certificates can itself be expensive; no algorithm to compute full ANFs of arbitrary circuits efficiently is claimed.

For quadratic maps, the first kernel consists of the intersection of radicals of the polar bilinear forms. On that space the remaining constant derivatives are linear and the second kernel gives the exact periods, including the linear terms. This is important: vanishing polar derivatives alone is insufficient (linear affine functions have zero polar form). For arbitrary degree the filtration replaces this quadratic-specific argument.

## 3. Nonlinear orbit family: equality and full polynomial span both miss compression

Let M=2^k, d=M^2+2M. Free data are H_j[t], z_i, w_t, with all indices in GF(2)^k. Define P_t=XOR_j H_j[t XOR j]. These M linear forms have disjoint support, hence rank M. Shared query q belongs to Bob. Forward responses are
    f_i(q)=P_(q XOR i) XOR (z_i AND w_(q XOR i)),
together with the 2M raw z,w bits as direct ports. Bob may select any forward signal; in particular the intended comparison target is a function with injective residuals on all d data bits (e.g. a lookup with extra raw-bit selection). This circuit is a rejected candidate for such a target, not an implementation of it or a new physical SAT grammar.

For each q the entire 3M-bit forward vector is surjective: choose z,w arbitrarily, then prescribe each independent P_t to produce the chosen f_i. Hence even per-history joint entropy is full. All M^2 nontrivial response polynomials are distinct, including modulo constant, because z_i w_t occurs in exactly one. The full GF(2) coefficient span of all responses modulo constants has rank exactly M^2+2M=d: every f has a private degree-two monomial, and all raw z,w linear functions are independent. Thus treating the rank of general nonlinear function coefficients as a capacity upper estimate does NOT detect this deficit. Such a rank is a valid code-length upper bound (encode a basis of functions), but not exact log image except in the affine case.

Nevertheless every response depends only on (P,z,w). The joint code recovers z,w from direct ports and every P_t by subtracting the private product from a response. Thus image size is exactly 2^(3M), and its period space consists precisely of translations fixing all P,z,w. Its dimension is M^2-M, codimension 3M. The ratio d/(3M)=(M+2)/3 grows unboundedly. Every raw data bit is essential to the joint map. This is a stronger kind of correlation than merely identical or linearly dependent functions: the functions are polynomially related through a smaller linear sketch of their *arguments*.

### Actual signed AIG and full previous quotient flow

Implement conditional XOR permutations of the H rows as in the previous orbit example, each row initialized H_j[i XOR j], then k stages of simultaneous mux(q_l,entry,entry XOR 2^l). Also permute the w array similarly without the initial row shift. At final index i the row entries are H_j[q XOR i XOR j], and the w entry is w_(q XOR i). IMPORTANT: start the accumulation in output i by XORing H_i[q] with z_i AND w_(q XOR i), then XOR the other rows in fixed order. Do not first compute P_t as an explicit intermediate and then add the marker. In that alternative implementation the previous quotient already detects a shared bottleneck. The actual construction uses O(M^2 log M) signed ANDs (three per mux or XOR).

After fixing q, all muxes specialize to raw primaries. In the old quotient retaining structural hashing and affine aliases (even complete certified affine equality), choose the path from H_i[q] through the direct previous-accumulator AND branch and final AND of each XOR macro to f_i(q). Every gate on this path after the source is nonlinear: each completed accumulator has the marker monomial z_i w_t (t=q XOR i), and the direct branch has a monomial containing both marker variables times its new data input (for the first XOR this is H_i[q]). Every chosen path vertex depends on no other z/w coordinates. Distinct (i,t) therefore have inequivalent such path functions, even up to complementation. Within one path the alternating branch and completed accumulator have different degrees (3 vs 2); branch marker triples use different data inputs, and successive accumulator linear parts strictly grow. So the path vertices do not collide with one another or with another chosen path under structural hashing. A structural alias to an off-path copy preserves its operand representatives; no affine alias can bypass a nonlinear path vertex. Initial sources H_i[q] are distinct over all i,q. Raw z,w use zero-length direct port paths. This yields d unit vertex-disjoint paths in the shared-source quotient, certifying full previous quotient flow. This does NOT assert the same for arbitrary nonlinear semantic resynthesis or arbitrary choice of exact equivalent-function representatives. The regression uses exact ANFs to certify affine aliases and the actual path edges.

Older exact individual capacities also suffice: vary only H_i, fix all z,w and other rows to zero, so the chosen accumulator path after its own mux carries its full M-bit response across independent q values; each selected mux branch has its own leaf-count response capacity. The chosen paths for different i before specialization live in distinct row and output chains, with z,w zero-length direct paths. This gives full causal virtual flow. Correct lookup/mux controls remain inexpensive, so the new test is not an unrestricted minimum-size lower bound.

For a coefficient submatrix A_(J,I), fixing other data gives a linear map of rank r on the selected sources, so each separating cut has >=r unit capacity; these are genuine rank lower bounds on submatrix flow, unlike the period codimension for general nonlinear maps.

The same prior Python replay implements shared-witness restriction
    F(H,S,Q)=OR_(t in Q) AND_(i in S) H_(i,t)
with independently programmable selected rows S and allowed witness columns Q. For ell a power of two and ell=Theta(log m) <=(log2 m)/2, use k=log2 ell witness variables, P=2^ell patterns, base the least power of two >=2P+k. IDs base+p (active dictionary) encode the bit of p selected by the common existential address, via one clause per address forcing the appropriate literal. IDs base+P+p (parking dictionary) are forced true by unit clauses. One unit base+Q enforces allowed witness mask. Each data row has one positive unit with active/parking tag bit and low ell pattern bits. All variable IDs are canonical common-width, with the low ell digits encoding data once, the next digit row selection (inverted polarity), and low digits of the single Q unit encoding witness mask once. Clause length is invariant. Dictionary overhead O(2^ell ell^2 (1+log ell))=o(m ell); total word length Theta(m ell), no copied free coordinates. The prior replay tested 128 actual grammar cases, 384 exact one-coordinate mutations and max word 224508 bits. No new padding or guarded-slice replay.

Rank proof over R or GF(2): for fixed nonempty row set S, inclusion-exclusion over nonempty subsets of Q spans precisely the monomials on rectangles S x T for T nonempty; the triangular inclusion-exclusion matrix is invertible in either field (diagonal +/-1). Distinct square-free monomials are independent as Boolean-cube functions (Möbius inversion); empty S contributes constant 1, empty Q contributes zero. Rank is 1+(2^m-1)(2^ell-1). One-way data-to-query exact cost m ell (querying single row/column retrieves every bit), receiving party outputs. One-way query-to-data cost ceil(log2(2+(2^m-1)(2^ell-1)))=m+ell: all nonempty S,Q yield distinct nonconstant functions by their minimal positive supports; constant zero and one account for two additional residuals. Two-way total Theta(m+ell) by rank and sending query then answer. Five exhaustive small matrices verified. All-selected query has GF(2) degree m ell because product of all column terms occurs once. If a one-way interface carries only affine data functions, receiving side needs >=m ell-1 binary gates for that query. Formal binary-circuit degree <=s+1 follows by introducing gate variables and substituting in reverse topological order, reducing squares in the Boolean ring after each substitution (each binary substitution increases degree by at most one). With messages of degree <=D, same argument gives s_B >= ceil(m ell/D)-1 for D>=1. These are directional restrictions; the entire shared-witness function has O(m ell) gates via masked rows and column conjunctions/OR, so not an unconditional superlinear example.

## 6. Next direction

The period invariant distinguishes joint information from linear span of nonlinear response functions. It cannot itself charge multiplication cost: a small linear sketch may be followed by arbitrary nonlinear decoding, while aperiodicity need not mean high image entropy. A concrete next target is to constrain the nonlinear computations that realize the huge rectangular response span for shared existential witnesses under varying cut directions, using actual gate-specific polynomials or certified affine restrictions. Do not sum ranks or period codimensions from overlapping scenarios as if they were independent gates; retain shared gate budgets and valid residual demands. Native agent: independently audit the filtration linearity and quotient-path argument; consider bounded-degree ANF certificates on stable original IDs.
