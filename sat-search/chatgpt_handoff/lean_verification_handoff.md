# Lean research verification

The workflow [.github/workflows/lean-verification.yml](../../.github/workflows/lean-verification.yml) is in the repository root. It runs on pushes to master changing the workflow or sat-search/chatgpt_handoff/lean/**, and can be launched manually from the repository Actions tab. Only trusted repository pushes/manual dispatch are used; no pull_request_target event or repository secrets. Read-only permissions, checkout credentials not persisted, timeout 90 minutes, cancel superseded runs.

The workflow fetches exact upstream definitions in a temporary directory, verifies the toolchain and lockfile, installs Lean using the pinned upstream installer, fetches Mathlib cache, builds Mathlib and PEqualNP.Defs without the outside submissions, and checks each research .lean file independently with warnings treated as errors. Files should import Mathlib and PEqualNP.Defs, be self-contained (not import other unbuilt handoff files), and print axioms of their final theorems for audit. Lean warnings-as-errors rejects ordinary sorry warnings but is NOT an automated transitive axiom allowlist or the upstream authoritative checker; no claims of desk acceptance. Do not put arbitrary third-party code in these trusted research files.
