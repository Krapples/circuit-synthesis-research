# Cross-history equivalence quotient and optimal capacitated gate charges

Date: 2026-11-26. Base [47dca20](https://github.com/Krapples/circuit-synthesis-research/commit/47dca200e6096b38706b7ecea866be0c921c2287). Extends [joint_history_handoff.md](joint_history_handoff.md). This round strengthens the lifted network by merging certified equal signals across DIFFERENT histories, strengthens shortest-path charging to minimum-cost feasible full flow, and characterizes optimal charge allocation by LP duality. Explicit families give unbounded gaps over previous exact individual and disjoint-history capacity tests, independent shortest paths, and uniform history weights. L-clb-036 remains open. No new unrestricted superlinear minimum-size bound, Lean proof, production solver change, or literature-priority claim.

## 1. Cross-history quotient

Retain the joint-response model: original DAG regions A,B, output B, data sources S in A, other A inputs fixed to public constants; common history set H over reverse ports containing all actual histories across legal (x,y). For each h in H the local A DAG computes a vector of Boolean functions of the SAME free data x. For a causal cut K (or K=forward ports F), joint response code J_K(x) records those values for every h.

The disjoint-copy network from the previous round makes one specialized DAG for each h and shares only the primary data sources. It does not identify equal computed Boolean functions across h. This is an avoidable relaxation.

**Construction.** Process original vertices in topological order, and at each vertex process all histories. Maintain signed aliases to constants, shared primaries, or earlier retained representative gate copies. Substitute the feedback constants of h, and use sound constant folding and structural hashing ACROSS the entire collection. Certified affine forms over GF(2), including affine forms obtained from a verified XOR/XNOR macro, can be hashed globally as well. Merge only proved equal or complementary Boolean functions on ALL data assignments, not just observed assignments or the reachable histories of a single data row. Keep the earliest existing representative with its original gate ID and its already justified operands. A nonaliased gate copy remains a binary AND with the original gate ID as its label. Different histories of one original gate may have different functions, and need not merge. All retained edges connect to representatives created earlier; hence the resulting network is a DAG, not a cyclic contraction of arbitrary equivalence classes. No new gate function or resynthesized subgraph is introduced. The output representatives for every (v,h) are preserved, including signed aliases.

Prune to the joint output cone. Denote this quotient DAG by Q_K. Give its vertices unit capacity, with one shared source vertex for each free physical primary and a supersource/sink as before. Let q(K) be maximum integral flow from S to the nonconstant output representatives of J_K. Infinite edges have capacity |S|+1. Every vertex cut supplies a one-bit-per-vertex code for all representative outputs: recursively evaluate the quotient DAG stopping at cut vertices, since no unencoded free source can be reached. Thus

    log2 N <= log2 |image J_K| <= q(K) <= |S|.

The first inequality is the earlier causal reconstruction theorem, including data-dependent feedback and arbitrary extensions of unobserved later reverse coordinates. The quotient code reconstructs joint responses, not a hypothetical simultaneous physical evaluation of all histories. Signed aliases do not require extra bits. Certified equivalences can involve different original gate IDs; each retained copy is charged to its own representative's actual original ID.

This is a noncircular, phase-specific certificate for known signed AIG operands, using simple algebraic identities. It is not a complete equivalence test and not a bare-topology impossibility criterion for arbitrary gate functions. The checker uses explicit XOR constructor provenance for its cross-history affine pass; this is valid for its constructed circuits, but a production application to arbitrary AIGs must recognize and certify the macro's actual operands as in the prior affine checker. No equality is inferred from finite test samples. We do not assert that an arbitrary choice of equivalent representatives or the quotient-flow numerical bound always dominates every disjoint-copy-flow estimate: use the minimum of valid capacity certificates. The proof itself does not require monotonicity.

## 2. Cross-history correlation example with full rank in every history

Let M=2^k and r=M. Write data H_j[t] with j,t in GF(2)^k, and let Bob own q and output-selection index i. Construct r forward responses

    f_i(q) = XOR_(j in GF(2)^k) H_j[q XOR i XOR j].

Let P_t = XOR_j H_j[t XOR j]. These M parities have disjoint supports, each containing r bits, and are independent linear forms. Then f_i(q)=P_(q XOR i). At every FIXED q the r outputs are a permutation of M independent parities, so the per-history response vector has full GF(2) rank M. Across ALL histories it is the SAME M parities permuted. The complete joint image has exactly 2^M elements, not 2^(M^2). Every physical data bit is essential in the resulting scalar function (Bob selects i), but the joint map is not injective.

The intended target is two-address INDEX H_i[q], or the earlier enabled lookup on the domain selecting one group with common address. That target has M^2 distinguishable data rows. These orbit-parity circuits are REJECTED candidates for that target, not circuits computing it.

### Older tests fail, even with exact local capacities

First realize f_i(q) using separate A-side mux trees for H_j[q XOR i XOR j] and an XOR chain starting with H_i[q] (other j in any fixed order). With only row H_i varying and all other rows zero, the i-th forward response has M independent bits across q. At each branch of the ordinary mux H_i[q], exact individual formal response log-cardinality is at least the number of distinct leaf data sources carried by that branch. Along the direct branch and output of every XOR in f_i's chain, varying H_i alone preserves the entire M-bit response. Route all M source units of row i through its own mux H_i[q] and that direct XOR chain. Paths for different i use disjoint chosen A gate sets. This supplies full M^2 flow under exact individual capacities and hence passes EVERY previous individual causal cut. q ranges independently of all data, so the partial-response coloring also equals the exact local response count. No need for artificial extra history cardinality.

For disjoint specialized histories, at any q all mux outputs simplify to the selected raw primary; each f_i(q) is a parity of a disjoint set of r primaries. All M such supports are disjoint, so the specialized XOR chains (including their internal nonconstant forms) remain disjoint up to primary sharing within one chain. Choose source H_i[q] at history q, and route to f_i(q). Across histories these sources are all distinct. Thus the old disjoint-copy affine lifted flow reaches M^2 as well, even with the shared source capacity. Per-history rank is genuinely full, not a case of missing within-history affine simplification.

But global affine equality identifies all occurrences of P_t across histories. The quotient output cut has M vertices and hence q(F)<=M. Exact joint image size supplies the reverse inequality, so q(F)=M. The separation factor M is unbounded. This captures correlations that the last round's same-history affine obstruction does not.

### Shared permutation implementation

The above separate mux implementation costs O(M^3) gates. A smaller actual AIG computes the same counterexample using a conditional XOR permutation of each row. Initialize W_j[i]=H_j[i XOR j]. For l=0..k-1, replace every entry simultaneously by mux(q_l, W_j[i], W_j[i XOR 2^l]), with the old array as input to the next one. At the end W_j[i]=H_j[q XOR i XOR j]. Then XOR each column, starting column i with W_i[i], and use a B-side selector on the outputs.

There are M rows, M entries per row and k stages, each mux three signed ANDs. Including column XORs and output selection, total <=3 M^2 k +3 M(M-1)+3(M-1)=O(M^2 log M). For each chosen output W_i[i] its backwards cone within row i is a full mux tree: at depth l backwards there are 2^l distinct indices differing only in already encountered shift bits, and each has two different predecessors in the next layer. Distinct branches in that cone do not merge (different index subsets). Each selected branch's exact response cardinality suffices for the leaf data units on it, because the q bits are independent. Row i paths through this cone then its own column's direct XOR chain are disjoint from the chosen paths of other rows. Thus all earlier exact individual and disjoint-copy capacities again pass M^2. Cross-history quotient still has capacity exactly M. This is a quasi-linear-size candidate counterexample with every data bit essential. It is not a new SAT lower bound or a claim that correct lookup circuits require such a network.

## 3. Capacitated gate charge: preserve competition for paths

In an injective residual setting the disjoint-copy or quotient graph has full feasible flow of value |S|. Label each retained gate copy z by its actual original gate v(z), with copy set C_v. Let lambda_z>=0 be nonnegative costs satisfying

    sum_(z in C_v) lambda_z <= 1  for each original gate v.

Primary vertices and other edges have zero cost. Let P be the compact convex polytope of feasible full flows, and let l_z(f) be load of copy z, at most one. For fixed lambda, define

    B(lambda) = min_(f in P) sum_z lambda_z l_z(f).

This is ordinary minimum-cost flow with vertex splitting and full flow demand; it has an integral optimizer. Every feasible flow costs at most one per original gate, hence B(lambda)<=s_A. The previous independent shortest-path metric equals the relaxed min-cost problem in which copy capacities are nonbinding (shared source supplies still one). Thus the new B(lambda) is at least that previous lower bound. This is not a physical routing statement, and no new data-dependent choice of circuit is allowed. The entire virtual network is fixed before the optimization.

**Exact optimum over cost budgets.** By finite-dimensional LP/minimax duality,

    B* = max_(lambda feasible) min_(f in P) sum_z lambda_z l_z(f)
       = min_(f in P) sum_v max_(z in C_v) l_z(f)
       <= number of live representative original gates <= s_A.

For the last equality, for a fixed f the best budget for v concentrates one unit of cost on a maximally loaded copy. The compact convex domains and bilinear objective justify swapping max/min. Equivalently introduce a variable u_v>=l_z(f) for every z in C_v and minimize sum_v u_v over full-flow constraints. This gives a polynomial-size LP in the explicit expanded network. The optimizer on the right may be fractional even though each fixed-cost min-cost-flow optimizer can be integral. Do not replace the right side by the minimum number of distinct gate labels touched by an INTEGRAL flow: that is a different potentially larger quantity and is not the derived dual. This exact characterization applies to the specified virtual network, not the true minimum circuit size.

Alternative computation: master LP maximizes t over feasible lambda and inequalities t<=lambda dot l(f) for all integral full flows f. Use a min-cost-flow separation oracle to find a violated flow. Only finitely many integral flow load vectors exist; exact constraint generation terminates if each violated constraint is added. The checker uses a simple floating-point simplex and min-cost flow implementation, with a 300-iteration cap and numerical tolerance, not certified exact rational LP. The explicitly proved gaps below have exact analytic certificates. Production exclusion would require rational feasible weights and verified min-cost dual potentials (or another exact certificate). A min-cost oracle returning a feasible flow alone is an UPPER bound on the minimum, not a certified lower bound; the implementation is an experiment, not a formal certificate generator.

### Multi-scenario extension (paper only)

Given any finite collection of legal partitions/restrictions, each with its own verified injective residual demand and full virtual flow polytope P_j, allocate one cost budget per ORIGINAL gate across all copies in ALL scenarios. Then sum_j min_(f_j in P_j) cost_j(f_j)<=s, by summing the per-gate budget constraints. The same minimax proof gives the optimized value min_(f_j) sum_v max_(j,z labelled v) l_z(f_j). This allows valid simultaneous obligations across overlapping partitions without assuming disjointness. It is at least the maximum of the individual optimized bounds and can add independent gate costs when labels are disjoint. No experiment or superlinear SAT charge from many scenarios is asserted. In particular a worst-case choice of legal cuts alone does not prove large numerical value.

## 4. Two exact unbounded gaps in charging

**Congestion gap (no feedback).** Data x,y,z_1,...,z_L in A. Forward outputs are g=x XOR y, h=x XOR z_1 XOR ... XOR z_L (serial chain of XOR macros), and all z_i directly. Bob selects any output (pad unused selectors by repeated output). This output family is injective in all L+2 data bits: read z_i, recover x from h and then y from g. Under single-history specialization all the indicated XOR macro gates remain live (distinct nonconstant forms, no aliases collapsing the chain). Each XOR traversed from either input contributes two AND gate vertices in a path. Individual shortest paths choose g for both x and y, so total charge 4; z_i choose zero-length ports. But y can exit only through g, whose unit capacity is exhausted. Therefore a feasible full flow must route x through the entire chain h. The other data can take their direct ports, so minimum full-flow cost is exactly 2L+2 with all copy costs one, also optimal among feasible budgets. No longer double-assign the g port. L=32 tested gives 4 vs 66. This is a lower bound on the count of gates in that specified A-side architecture, not a minimum complexity result for the Boolean function: it can be implemented differently.

**History dilution gap.** Data x,y,z in A; Bob holds k feedback bits q and a port-selection query. Forward outputs y,z directly and g=y XOR mux([q!=0],x,z), where mux chooses x at zero and z otherwise. Residual map injective (at zero recover x using g and y). Let H=2^k. In every history final XOR gates survive, but x has paths to a forward output only in the q=0 copy. The mux simplifies to x or z. Every full flow must route x via two gates of that XOR at zero; y,z may use direct ports. Uniform charges 1/H give exact min-cost 2/H. Concentrate the original XOR gate budgets at the zero history: exact min-cost 2, and cannot exceed 2 because the same explicit full flow uses only two gate copies. Thus optimizing weights gives factor H, arbitrarily large, even after respecting path competition. Quotient merges identical nonzero copies and gives uniform cost one in this example; optimization still gives two. The absolute bound remains small; do not confuse multiplicative improvement with a large universal lower bound.

## 6. Next milestone

The strongest justified charge now has an explicit optimization characterization. The remaining hard step is to force its optimum to be superlinear for a family of actual SAT circuits, or to prove an obstruction to this approach. Possible route: use simultaneous legal existential-witness restrictions as scenarios, preserving stable original gate labels, then bound the sum of maximum copy loads in EVERY feasible collection of flows.
